## 电子文档的历史

---

|     年代      | 软件                                             | 设计理念               | 关联的数据协议                            |
| :---------: | :--------------------------------------------- | :----------------- | ---------------------------------- |
| 1990 ~ 2005 | Office 全家桶（ `word` / `Excel` / `Power Point` ） | 单一用途，各自为营          | 争对搜索引擎的 `sitemap.xml`              |
| 2005 ~ 2015 | Wiki, 百科,                                      | 开始统一整理，收集，可以在网页上展示 | 正对爬虫的  `robots.txt`                |
|  2015 ~ 现在  | 现代知识库 `Notion`, `飞书`, `Obsidian`               | 人人可交互， 文档之间开始联动    | 针对大语言模型的 `llms.txt` 模型 markdown 格式 |

---
### 知识库

1. 文档之间可以管理，互相导航，联动
2. 数据格式多样：文档，表格，图片，视频，图表
3. 链接和分析整理，检索

### All In One  

---

### 基础

Obsidian 是一个以 `markdown` 为基础的知识库系统

1. 本地，可离线使用。不同于**飞书**，**雨雀**在线系统
2. 插件系统: 支持更加丰富的功能

### Markdown

- AI 时代，markdown 是和大模型交互的 `一等公民`

-  `mermaid` 等也是相关产物

- `microsoft office` --> `microsoft 365` ,往 web 化发展

- `https://github.com/microsoft/markitdown` 微软的工具在把 word, ppt, excel 转换成 `markdown`

| **序号** | **功能**                                | 标签    | **描述**                                           |
| ------ | ------------------------------------- | ----- | ------------------------------------------------ |
| 1      | 脑暴白板 (Canvas)                         | #内置功能 | 在无限画布上进行自由布局和连接想法，适合头脑风暴、项目规划和知识整理。              |
| 2      | 绘图 (Excalidraw)                       |       | 手绘风格的绘图工具，适合绘制流程图、示意图等，支持创意表达。                   |
| 3      | 项目管理 (Projects)                       |       | 管理复杂项目，适合任务分解和进度跟踪。                              |
| 3      | 任务管理（Kanban, Calenda）                 |       | 看板式任务管理，适合可视化工作流和任务分配。<br>日程安排和任务提醒，适合时间管理和计划制定。 |
| 4      | 类似 Excel 的表格 (Spreadsheet)            |       | 创建和编辑类似Excel的表格，适合数据整理和分析。                       |
| 5      | 思维导图 (Mind Map)                       |       | 将笔记转换为思维导图，帮助直观组织和理解信息。                          |
| 6      | PPT (Advanced Canvas, Advanced Slide) | #内置功能 | 将笔记转换为幻灯片，适合演示和报告。                               |
| 7      | 接入大模型 (Copilot)                       |       | 自动生成Mermaid流程图、润色文档、整理内容等，提升工作效率。                |
| 8      | PDF 编辑 (PDF++)                        |       | 直接编辑和注释PDF文件，适合处理PDF文档。                          |
| 9      | 知识库分析 (Dataview)                      |       | 根据目录、时间、标签等生成表格、任务列表、日历图等，帮助分析和展示知识库内容。          |
| 10     | 魔改Obsidian样式 (Style Setting)          |       | 自定义字体、样式、栏宽、背景等，甚至详细到每个按钮的样式，打造个性化体验。            |
| 11     | 编辑增强 (Easy Typing, Emoji ShortCodes)  |       | 自动处理标点符号、括号配对、中英文混排空格，方便插入表情符号，提升编辑效率。           |
| 12     | 知识库同步（git)                            |       | 通过Obsidian Sync或第三方工具（如Git）实现知识库同步和协作，适合团队使用。    |
| 13.    | 统计图表（Charts）                          |       | 生成统计图表，可以和 Dataview 联动使用                         |
