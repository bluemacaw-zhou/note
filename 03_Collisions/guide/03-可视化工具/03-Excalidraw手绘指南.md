## 1. Excalidraw 基础

### 1.1 什么是 Excalidraw

**Excalidraw** 是一个虚拟白板工具，提供类似手绘的绘图风格。

**与 Canvas 的区别**：

| 特性 | Canvas | Excalidraw |
|------|--------|-------------|
| **类型** | 内置功能 | 内置插件 |
| **用途** | 组织内容 | 手绘图形 |
| **风格** | 结构化卡片 | 自由绘图 |
| **文件** | `.canvas` | `.excalidraw` |
| **适用** | 项目管理、知识网络 | 流程图、架构图 |

### 1.2 启用 Excalidraw

**步骤**：
1. 设置 → 第三方插件
2. 搜索 "Excalidraw"
3. 安装并启用

### 1.3 创建 Excalidraw

**方式一：命令面板**
1. `Ctrl/Cmd + P`
2. 输入 "Excalidraw"
3. 选择"创建新绘图"

**方式二：新建文件**
1. 新建文件
2. 选择 Excalidraw 类型
3. 输入文件名

## 2. 绘图技巧

### 2.1 工具栏介绍

| 工具 | 快捷键 | 用途 |
|------|--------|------|
| 选择 | `1` / `V` | 选择对象 |
| 矩形 | `2` / `R` | 绘制矩形 |
| 椭圆 | `3` / `O` | 绘制椭圆 |
| 菱形 | `4` / `X` | 绘制菱形 |
| 箭头 | `5` / `A` | 绘制箭头 |
| 线条 | `6` / `L` | 绘制线条 |
| 自由绘制 | `P` | 自由绘图 |
| 文本 | `T` | 添加文本 |
| 图片 | 拖拽 | 插入图片 |
| 橡皮擦 | `E` | 擦除内容 |

### 2.2 基础图形

#### 矩形

```markdown
步骤：
1. 选择矩形工具 (R)
2. 在画布上拖拽
3. 调整大小和位置
```

#### 椭圆

```markdown
步骤：
1. 选择椭圆工具 (O)
2. 在画布上拖拽
3. 按住 Shift 可绘制正圆
```

#### 箭头

```markdown
步骤：
1. 选择箭头工具 (A)
2. 拖拽绘制直线
3. 松开时选择箭头类型
```

### 2.3 样式设置

**边框样式**：
- 实线
- 虚线
- 点线

**边框粗细**：
- 细 (1px)
- 中 (2px)
- 粗 (4px)

**颜色选择**：
- 边框颜色
- 背景颜色
- 文本颜色

### 2.4 文本

**添加文本**：
1. 选择文本工具 (T)
2. 点击画布
3. 输入文本
4. 点击外部完成

**文本样式**：
- 字体大小
- 粗体/斜体
- 文本对齐

## 4. MCP 集成

### 4.1 什么是 MCP

**MCP (Model Context Protocol)** 是一个开放协议，让 AI 工具能够理解和操作 Excalidraw 图形。

**GitHub 项目**：https://github.com/excalidraw/excalidraw-mcp

### 4.2 MCP 集成场景

**AI 辅助绘图**：
- 描述需求，AI 生成流程图
- 自动化架构图创建
- 图形内容理解和转换

**配置步骤**：

1. 安装 Excalidraw MCP 服务器
2. 配置 AI 工具（如 Claude、Cline）
3. 开始 AI 辅助绘图

### 4.3 实用示例

**提示词示例**：
```
请创建一个用户登录流程的 Excalidraw 图：
1. 用户输入账号密码
2. 系统验证
3. 返回 JWT Token
4. 登录成功
```

## 7. 常见问题

### Q1：Excalidraw 与 Canvas 如何选择？

**A**：
- **项目管理、知识网络** → Canvas
- **技术图表、流程图** → Excalidraw
- **两者可以配合使用**

### Q2：导出的图片模糊怎么办？

**A**：
- 调整导出分辨率
- 使用 PNG 格式
- 检查是否是显示比例问题

### Q3：可以导入现有图表吗？

**A**：
- 支持导入 Excalidraw JSON 文件
- 支持导入图片作为参考
- 不支持导入其他格式

### Q4：如何在团队中协作？

**A**：
- 通过 Git 版本控制
- 添加注释说明修改内容
- 使用分支进行并行编辑
