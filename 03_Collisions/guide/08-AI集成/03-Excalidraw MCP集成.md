## MCP 简介

**什么是 MCP**？
- MCP (Model Context Protocol) 是 AI 模型与工具集成的协议
- Excalidraw MCP 允许 AI 理解和操作 Excalidraw 画板
- 支持自然语言生成和修改图形

**核心功能**：
- AI 生成图形
- 智能布局
- 图形描述
- 样式建议

## 安装配置

### 前置要求

1. **Excalidraw 插件**
   - 内置插件，直接启用
   - 确保版本 >= 2.2.0

2. **MCP Server**
   - 安装 Node.js
   - 安装 MCP 服务器

### 安装步骤

```bash
# 1. 安装 Excalidraw MCP Server
npm install -g @excalidraw/excalidraw-mcp-server

# 2. 配置 Obsidian
设置 → Excalidraw → MCP
Enable MCP: true
Server URL: http://localhost:3000

# 3. 启动服务器
excalidraw-mcp-server start
```

### Copilot 集成

```yaml
设置 → Copilot → MCP
Enable MCP: true
MCP Servers:
  - name: excalidraw
    url: http://localhost:3000
```

## AI 绘图功能

### 1. 自然语言生成

**描述生成图形**：
```
请创建一个流程图：
- 开始节点：圆形，"用户登录"
- 处理节点：矩形，"验证身份"
- 判断节点：菱形，"验证成功？"
- 结束节点：圆形，"进入系统"
```

**AI 自动布局**：
```
请优化布局，使流程更清晰
```

### 2. 智能样式

**样式建议**：
```
请为这个架构图选择合适的颜色：
- 前端组件：蓝色系
- 后端服务：绿色系
- 数据库：橙色系
```

**主题应用**：
```
应用现代简约主题
使用柔和的配色
```

### 3. 图形描述

**生成说明**：
```
请描述这个流程图的逻辑
```

**文字生成**：
```
为这些节点生成合适的标签
```

## 实践案例

### 案例1：系统架构图

**AI 生成**：
```
请创建一个 Web 应用架构图，包含：
- 前端：React 应用
- 后端：Node.js API
- 数据库：PostgreSQL
- 缓存：Redis
- 消息队列：RabbitMQ

使用标准架构图标，清晰展示数据流向
```

**结果**：
- AI 自动创建架构图
- 使用合适的形状和颜色
- 自动连接组件
- 添加标签说明

### 案例2：思维导图

**中心主题**：
```
创建思维导图，主题是"Obsidian 使用技巧"
包含4个主要分支：
1. 核心功能
2. 插件生态
3. 协作方法
4. 最佳实践
```

**AI 扩展**：
```
为"核心功能"分支添加子节点：
- 双链接
- 标签系统
- Canvas 白板
- 块引用
```

### 案例3：流程图

**业务流程**：
```
创建用户注册流程：
1. 用户填写表单
2. 验证邮箱
3. 设置密码
4. 完成注册

用标准流程图符号
```

**AI 优化**：
```
优化流程图布局
使主要路径更清晰
添加异常处理分支
```

## 最佳实践

> [!tip] 使用建议
> 1. **清晰描述**：提供详细的图形描述
> 2. **迭代优化**：逐步完善图形
> 3. **人工审核**：AI 生成后人工调整
> 4. **保存模板**：保存常用的图形模板

> [!tip] 提示词技巧
> 1. **指定类型**：明确图形类型（流程图、架构图等）
> 2. **数量说明**：指定节点和连接的数量
> 3. **样式偏好**：说明颜色和风格偏好
> 4. **布局要求**：指定布局方向（水平/垂直）

## 常见问题

### Q1：MCP 连接失败？

**A**：
- 检查 MCP 服务器是否运行
- 确认 URL 配置正确
- 查看防火墙设置

### Q2：AI 生成不准确？

**A**：
- 提供更详细的描述
- 使用示例参考
- 手动调整后再优化

### Q3：性能问题？

**A**：
- 减少图形复杂度
- 分步创建大型图形
- 优化 AI 提示词
