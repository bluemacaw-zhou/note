## Icon Folder 文件夹图标

### 插件简介

**Icon Folder** 允许为文件夹和笔记设置自定义图标。

**功能**：
- 文件夹图标
- 笔记图标
- 表情符号图标
- 自定义 SVG 图标

### 安装配置

```yaml
# 安装
设置 → 社区插件 → 浏览 → 搜索 "Icon Folder" → 安装启用

# 配置
Icon Folder:
  Icon in Navigation: true      # 导航栏显示图标
  Icon in Title: true           # 标题显示图标
  Move File: true               # 允许拖动
```

### 使用方法

**方式1：右键菜单**
- 右键点击文件夹/笔记
- 选择 "Set icon" 或 "Change icon"
- 选择图标

**方式2：Frontmatter**
```markdown
---
icon: 📝
---
```

**方式3：设置面板**
- 设置 → Icon Folder
- 浏览并选择图标
- 添加到文件夹

## Colored Tags 彩色标签

### 插件简介

**Colored Tags** 为标签添加颜色和样式。

**功能**：
- 标签颜色
- 标签背景色
- 标签样式
- 分组显示

### 安装配置

```yaml
# 安装
设置 → 社区插件 → 浏览 → 搜索 "Colored Tags" → 安装启用

# 配置
Colored Tags:
  Color Per Tag: true           # 每个标签独立颜色
  Show In Reading View: true    # 阅读视图显示
```

### 设置颜色

**方式1：设置面板**
- 设置 → Colored Tags
- 添加标签
- 选择颜色

**方式2：配置文件**
```yaml
Colored Tags:
  tags:
    - tag: "#重要"
      color: "#ff0000"
      background: "#ffe6e6"
    - tag: "#进行中"
      color: "#00aa00"
      background: "#e6ffe6"
```

### 颜色方案

**优先级标签**：
```yaml
优先级:
  - "#紧急": red
  - "#重要": orange
  - "#普通": blue
  - "#可选": gray
```

**状态标签**：
```yaml
状态:
  - "#进行中": blue
  - "#已完成": green
  - "#已取消": gray
  - "#阻塞": red
```

**类别标签**：
```yaml
类别:
  - "#技术": purple
  - "#产品": yellow
  - "#设计": pink
  - "#管理": cyan
```

## 最佳实践

> [!tip] 图标使用
> 1. **统一风格**：使用相同类型的图标（如都使用表情符号）
> 2. **语义明确**：图标要能表达文件夹/文件的内容
> 3. **数量控制**：不要使用太多不同图标
> 4. **定期审查**：移除不必要的图标

> [!tip] 标签颜色
> 1. **建立系统**：为标签分类建立统一颜色方案
> 2. **避免过多**：不要为每个标签都设置不同颜色
> 3. **高对比度**：确保文字清晰可读
> 4. **一致性**：相同含义的标签使用相同颜色
