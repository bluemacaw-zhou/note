## Highlightr 内容高亮

### 插件简介

**Highlightr** 提供多种颜色的高亮功能，突出重要内容。

**功能**：
- 多种颜色高亮
- 快捷键支持
- 导出时保留样式

### 安装配置

```yaml
# 安装
设置 → 社区插件 → 浏览 → 搜索 "Highlightr" → 安装启用

# 配置
Highlightr:
  Default Color: yellow         # 默认颜色
  Formatters:                   # 格式化器
    - yellow: H
    - red: R
    - blue: B
    - green: G
```

### 使用方法

**高亮标记**：
```markdown
==黄色高亮==

==红色高亮==

==蓝色高亮==

==绿色高亮==
```

**快捷键**：
- 选中文字
- 按 `Ctrl/Cmd + E` 切换高亮
- 或使用格式化器：`HH` 包裹文字

### 高亮颜色

| 颜色 | 格式化器 | 说明 |
|------|----------|------|
| 黄色 | `H` 或 `HH` | 默认高亮 |
| 红色 | `R` 或 `RR` | 重要内容 |
| 蓝色 | `B` 或 `BB` | 技术术语 |
| 绿色 | `G` 或 `GG` | 完成状态 |

## Admonition 提示块

### 插件简介

**Admonition** 创建类似技术文档的提示块。

**支持的提示类型**：
- note（笔记）
- abstract（摘要）
- info（信息）
- todo（待办）
- tip（提示）
- success（成功）
- question（问题）
- warning（警告）
- failure（失败）
- danger（危险）
- bug（缺陷）
- example（示例）
- quote（引用）

### 安装配置

```yaml
# 安装
设置 → 社区插件 → 浏览 → 搜索 "Admonition" → 安装启用

# 配置
Admonition:
  Auto Collapse: false         # 自动折叠
  Copy Button: true            # 显示复制按钮
  Version: "=7.0.0"            # Obsidian 版本
```

### 使用方法

**基本语法**：
```markdown
```admonition note
title: 提示标题
这里是提示内容
```
```

**简写语法**（Obsidian 内置 Callout）：
```markdown
> [!note] 提示标题
> 这里是提示内容
```

### 常用提示类型

**Note（笔记）**：
```markdown
> [!note] 笔记
> 这是一条普通笔记
```

**Tip（提示）**：
```markdown
> [!tip] 提示
> 这是有用的提示信息
```

**Warning（警告）**：
```markdown
> [!warning] 警告
> 这是一条警告信息
```

**Important（重要）**：
```markdown
> [!important] 重要
> 这条信息很重要
```

## Callout 语法

### 基础用法

**Note**：
```markdown
> [!note] 标题
> 内容可以多行
> 支持折叠
```

**可折叠 Callout**：
```markdown
> [!faq]- 可以折叠
> 点击箭头展开/折叠内容
>
> ==还可以使用高亮==
```

**嵌套 Callout**：
```markdown
> [!info] 外层
> > [!warning] 内层
> > 嵌套的内容
```

### 常用类型

| 类型 | 说明 |
|------|------|
| `note` | 笔记 |
| `abstract` | 摘要 |
| `info` | 信息 |
| `todo` | 待办 |
| `tip` | 提示 |
| `success` | 成功 |
| `question` | 问题 |
| `warning` | 警告 |
| `failure` | 失败 |
| `danger` | 危险 |
| `bug` | 缺陷 |

## 最佳实践

> [!tip] 使用建议
> 1. **适度使用**：不要过度使用高亮和提示块
> 2. **语义明确**：选择合适的提示类型
> 3. **内容简洁**：提示块内容要简明扼要
> 4. **保持一致**：在整个知识库中使用统一的风格

## 常见问题

### Q1：高亮不显示？

**A**：
- 检查 Highlightr 插件是否启用
- 确认语法正确（`==内容==`）
- 尝试重启 Obsidian

### Q2：Callout 折叠不了？

**A**：
- 使用 `-` 符号：`> [!note]-`
- 确认使用的是 Callout 而非 Admonition

### Q3：导出后样式丢失？

**A**：
- Admonition 插件样式导出时可能丢失
- 考虑使用 Pandoc 保留样式
- 或使用 Obsidian 内置 Callout
