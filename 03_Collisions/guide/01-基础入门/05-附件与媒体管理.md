# 附件与媒体管理

Obsidian 不仅擅长管理 Markdown 文档，也能很好地管理图片、PDF、视频等附件资源。正确的附件管理策略能让您的知识库更加整洁和专业。

## 1. 附件配置

### 1.1 推荐配置

为了确保附件在 Obsidian 和 Gitea 中都能正常显示，建议进行以下配置：

**设置路径**：`设置` → `文件与链接`

| 配置项 | 推荐值 | 说明 |
|--------|--------|------|
| **内部链接类型** | 基于当前笔记的相对路径 | 确保跨平台兼容 |
| **使用 Wiki 链接** | ❌ 关闭 | 使用标准 Markdown 链接 |
| **附件文件夹路径** | `attachments` | 子文件夹存放附件 |
| **附件文件名格式** | 按规则重命名 | 便于管理 |

### 1.2 配置详解

**内部链接类型**：

```markdown
# 推荐：基于当前笔记的相对路径

# 链接示例
[图片](../../attachments/image.png)

# 优点：
# ✅ 跨平台兼容
# ✅ Gitea 正常显示
# ✅ 移动库时链接有效
```

**附件文件夹路径**：

```
知识库/
├── attachments/          # 所有附件集中存放
│   ├── images/
│   ├── pdfs/
│   └── videos/
├── 项目文档/
└── 学习笔记/
```

**附件文件名格式**：

```
{{date:YYYY-MM-DD}}-{{value}}
```

例如：`2026-03-06-screenshot.png`

### 1.3 自动配置脚本

使用 **QuickAdd** 或 **Templater** 可以自动创建附件文件夹：

```javascript
// Templater 示例
<%*
  const attachmentFolder = "attachments/" + tp.date.now("YYYY-MM");
  await tp.file.create_new_folder(attachmentFolder);
*%>
```

## 2. 图片管理

### 2.1 插入图片

**方式一：拖拽**（推荐）
1. 将图片拖入编辑器
2. Obsidian 自动复制到附件文件夹
3. 生成链接：`![](image.png)`

**方式二：粘贴**
1. 截图或复制图片
2. 在编辑器中 `Ctrl/Cmd + V`
3. 自动保存并插入

**方式三：选择文件**
1. `Ctrl/Cmd + P` → "插入图片"
2. 选择文件
3. 插入链接

### 2.2 图片语法

**基础语法**：
```markdown
![替代文字](path/to/image.png)
```

**调整大小**：
```markdown
![图片|300]   <!-- 宽度 300px -->
![图片|300x200]  <!-- 300x200 -->
```

**Wiki 链接语法**（需开启 Wiki 链接）：
```markdown
[image.png](image.png.md)
[image.png|alt=替代文字|width=300](image.png|alt=替代文字|width=300.md)
```

### 2.3 图片组织

**按日期组织**：
```
attachments/
├── 2026-03/
│   ├── 2026-03-06-screenshot.png
│   └── 2026-03-06-diagram.png
└── 2026-02/
    └── ...
```

**按项目组织**：
```
attachments/
├── 项目A-用户中心/
│   ├── wireframes/
│   └── screenshots/
└── 项目B-订单重构/
    ├── diagrams/
    └── mocks/
```

### 2.4 图片插件推荐

**Image Toolkit**：
- 自动调整图片大小
- 批量转换格式
- 图片优化压缩

**Image Converter**：
- 转换图片格式（PNG ↔ WEBP）
- 自动压缩
- 批量处理

## 3. PDF 管理

### 3.1 PDF++ 插件

**安装**：`PDF++` 插件

**功能**：
- 在 Obsidian 中阅读 PDF
- 高亮和标注
- 提取文字和图片
- 嵌入特定页面

### 3.2 PDF 语法

**嵌入整篇 PDF**：
```markdown
[文档.pdf](文档.pdf.md)
```

**嵌入特定页面**：
```markdown
[文档.pdf#page=5](文档.pdf#page=5.md)
```

**嵌入页面范围**：
```markdown
[文档.pdf#page=1-3](文档.pdf#page=1-3.md)
```

**高亮标注**：

在 PDF++ 中选中文字后，可以：
- 高亮显示
- 添加笔记
- 创建块引用

**引用标注内容**：
```markdown
[文档.pdf#annotation=123](文档.pdf#annotation=123.md)
```

### 3.3 PDF 工作流

> [!tip] PDF 笔记工作流
> 1. **导入 PDF**：拖入 Obsidian
> 2. **阅读标注**：在 PDF++ 中高亮重要内容
> 3. **创建笔记**：为 PDF 创建关联笔记
> 4. **引用内容**：用块引用嵌入标注内容
> 5. **双链关联**：将笔记与 PDF 双向链接

**示例**：

```markdown
---
tags: [文献笔记]
source_pdf: 深度学习论文.pdf
---

# 论文笔记：深度学习

## 核心观点

[深度学习论文.pdf#page=3](深度学习论文.pdf#page=3.md)

> [!quote]- 作者观点
> 深度学习是机器学习的一个分支... [深度学习论文.pdf#annotation=1](深度学习论文.pdf#annotation=1.md)

## 个人思考

基于论文中的方法，我认为...

## 相关资料

- [另一篇相关论文](另一篇相关论文.md)
- [相关概念笔记](相关概念笔记.md)
```

## 4. 其他媒体文件

### 4.1 音频文件

**支持的格式**：MP3, WAV, M4A, OGG

**嵌入音频**：
```markdown
[音频.mp3](音频.mp3.md)
```

**使用 Media Extended 插件**：

支持更多格式和控制选项：
```markdown
[音频.mp3|controls](音频.mp3|controls.md)
```

### 4.2 视频文件

**支持的格式**：MP4, WEBM, OGG

**嵌入视频**：
```markdown
[视频.mp4](视频.mp4.md)
```

**在线视频**：

**YouTube**：
```markdown
![](https://www.youtube.com/watch?v=xxxxx)
```

**B站**（需要插件）：
```markdown
![](https://www.bilibili.com/video/BVxxxxx)
```

### 4.3 其他文件类型

**Office 文档**：
```markdown
[文档.docx](文档.docx.md)  <!-- 链接到文件，点击打开 -->
[表格.xlsx](表格.xlsx.md)
[演示.pptx](演示.pptx.md)
```

**代码文件**：
```markdown
`代码.js`  <!-- 行内代码链接 -->

[script.py](script.py.md)  <!-- 链接到代码文件 -->
```

**压缩文件**：
```markdown
[数据.zip](数据.zip.md)
[备份.tar.gz](备份.tar.gz.md)
```

## 5. Gitea 协作配置

### 5.1 关键配置

为了确保附件在 Gitea 中正常显示，必须配置：

| 配置项 | 必须设置 |
|--------|----------|
| **内部链接类型** | 基于当前笔记的相对路径 |
| **使用 Wiki 链接** | ❌ 关闭 |
| **附件文件夹路径** | `attachments` 或 `attachments/子文件夹` |

### 5.2 验证配置

**测试步骤**：

1. 在 Obsidian 中插入图片
2. 检查生成的链接格式：
   ```markdown
   ![](../../attachments/image.png)  ✅ 正确
   [image.png](image.png.md)  ❌ 错误（Wiki 链接）
   ```
3. 推送到 Gitea
4. 在 Gitea 中查看图片是否显示

### 5.3 常见问题

**问题 1：Gitea 中图片不显示**

**原因**：使用了 Wiki 链接或绝对路径

**解决**：
```markdown
# ❌ 错误
[image.png](image.png.md)
![图片](D:/vault/attachments/image.png)

# ✅ 正确
![](../../attachments/image.png)
```

**问题 2：移动库后链接失效**

**原因**：使用了绝对路径

**解决**：使用相对路径

**问题 3：中文文件名乱码**

**原因**：编码问题

**解决**：使用英文文件名或 URL 编码

## 8. 常见问题

### Q1：附件文件夹应该放在哪里？

**A**：推荐两种方案

**方案一：根目录统一管理**
```
知识库/
└── attachments/  # 所有附件
```

**方案二：分散管理**
```
项目A/
└── attachments/
项目B/
└── attachments/
```

**建议**：
- 个人知识库：方案一
- 团队项目：方案二

### Q2：如何处理大型附件？

**A**：
- **视频**：考虑托管在外部（如阿里云 OSS），用链接引用
- **大型 PDF**：可以拆分或压缩
- **设计素材**：使用专业工具管理（如 Figma），Obsidian 中链接

### Q3：图片太慢怎么办？

**A**：
1. **压缩图片**：使用 Image Converter
2. **转换格式**：PNG → WEBP
3. **延迟加载**：使用插件控制加载方式
4. **外部托管**：大型图片托管到图床

### Q4：如何批量重命名附件？

**A**：使用插件
- **File Explorer** 插件支持重命名
- **Rename** 插件批量处理
- 编写脚本自动重命名
