## 1. 标签系统（Tags）

### 1.1 标签语法

**单级标签**：
```markdown
#标签名
```

**多级标签**：
```markdown
#父标签/子标签/孙标签
```

**示例**：
```markdown
#Obsidian #知识管理 #项目/用户中心 #优先级/高 #状态/进行中
```

### 1.2 在文档中定义标签

**方式一：在 Frontmatter 中定义**（推荐）

```markdown
---
tags: [需求, 用户认证, 高优先级]
---
```

**方式二：在正文中使用**

```markdown
本文档描述用户登录功能的需求细节。

标签：#需求 #用户认证 #优先级/高
```

### 1.3 标签的最佳实践

> [!tip] 标签组织策略
> **按用途分类**：
> - **状态类**：`#状态/待办`、`#状态/进行中`、`#状态/已完成`
> - **优先级**：`#优先级/紧急`、`#优先级/高`、`#优先级/中`、`#优先级/低`
> - **项目类**：`#项目/用户中心`、`#项目/订单重构`
> - **类型类**：`#类型/需求`、`#类型/设计`、`#类型/开发`、`#类型/测试`
> - **技术栈**：`#Java`、`#SpringBoot`、`#Vue`、`#数据库`

**多级标签示例**：

```markdown
#技术栈/后端/Java/SpringBoot
#技术栈/前端/Vue
#技术栈/数据库/MySQL
#团队/后端组
#团队/前端组
```

### 1.4 标签与搜索

在标签面板中，可以：
- 点击标签查看所有带该标签的笔记
- 使用嵌套标签的层次结构
- 组合多个标签进行筛选

## 2. 链接系统（Links）

Obsidian 的核心特性是**双向链接**，让笔记之间建立智能关联。

### 2.1 双向链接 `[[]]`

**基础链接**：
```markdown
[文档名称](文档名称.md)
```

**带别名**：
```markdown
[文档名称|显示的别名](文档名称|显示的别名.md)
```

**链接到标题**：
```markdown
[文档名称#标题](文档名称#标题.md)
```

**链接到段落（块引用）**：
```markdown
[文档名称^blockid](文档名称^blockid.md)
```

### 2.2 嵌入引用 `![[]]`

**嵌入整个笔记**：
```markdown
[其他笔记](其他笔记.md)
```
> 这会在当前文档中显示其他笔记的完整内容

**嵌入特定章节**：
```markdown
[其他笔记#章节标题](其他笔记#章节标题.md)
```

**嵌入图片**：
```markdown
[图片.png](图片.png.md)
```

**嵌入 PDF**：
```markdown
[文档.pdf](文档.pdf.md)
```

**嵌入特定页面**：
```markdown
[文档.pdf#page=5](文档.pdf#page=5.md)
```

### 2.3 外部链接

**标准 Markdown 链接**：
```markdown
[百度](https://www.baidu.com)
[Gitea](http://10.106.51.205)
```

### 2.4 出链与反链

- **出链（Outgoing Links）**：当前文档引用的其他文档
- **反链（Backlinks）**：引用当前文档的其他文档

> [!info] 查看反链
> 在笔记右侧的「反向链接」面板中，可以看到：
> 1. **链接到此文件的笔记**：所有引用当前文档的笔记
> 2. **未链接的提及**：包含当前文档名称但未建立链接的文本

### 2.5 链接 vs 嵌入

| 特性 | 链接 `[[]]` | 嵌入 `![[]]` |
|------|-------------|-------------|
| 显示内容 | 仅显示链接文字 | 显示完整内容 |
| 用途 | 跳转到其他笔记 | 在当前笔记中展示内容 |
| 支持内容 | 文档、标题、段落 | 文档、标题、图片、PDF |
| 编辑影响 | 独立编辑 | 同步更新源文档 |

## 3. Callout 提示块

Callout 是 Obsidian 扩展的提示块语法，用于突出显示重要信息。

### 3.1 基础语法

```markdown
> [!类型] 标题
> 内容说明
```

### 3.2 支持的类型

| 类型 | 效果 | 适用场景 |
|------|------|----------|
| `note` | 💙 一般提示 | 注意事项、提醒 |
| `abstract` | 📖 摘要、总结 | 文档摘要 |
| `summary` | 📖 总结 | 内容总结 |
| `tldr` | 📖 太长不看 | 快速概览 |
| `info` | ℹ️ 信息 | 补充信息 |
| `todo` | ❗ 待办 | 待办事项 |
| `tip` | 💡 小贴士 | 有用建议 |
| `success` | ✅ 成功 | 成功提示 |
| `question` | ❓ 问题 | 常见问题 |
| `warning` | ⚠️ 警告 | 警告信息 |
| `failure` | ❌ 失败 | 失败提示 |
| `danger` | ⚠️ 危险 | 危险警告 |
| `bug` | 🐛 Bug | 缺陷说明 |
| `example` | 📖 示例 | 示例说明 |
| `quote` | 💬 引用 | 引用内容 |

### 3.3 Callout 示例

**Note（提示）**：
> [!note] 注意事项
> 这是提示信息，用于一般性提醒

**Tip（小贴士）**：
> [!tip] 效率技巧
> 按 `Ctrl/Cmd + K` 可以快速插入链接

**Warning（警告）**：
> [!warning] 重要警告
> 操作前请确保已备份重要数据

**Question（问题）**：
> [!question] 常见问题
> Q: 如何快速打开命令面板？
> A: 按 `Ctrl/Cmd + P`

**Example（示例）**：
> [!example] 实战示例
> ```markdown
> # 这是一个示例
> ```

### 3.4 可折叠的 Callout

**默认折叠**（`-`）：
> [!faq]- 可以折叠吗？
> 可以！在标题后添加 `-` 符号
> 内容默认隐藏，点击可展开

**默认展开**（`+`）：
> [!faq]+ 展开显示
> `+` 表示默认展开
> `-` 表示默认折叠

### 4.3 文本高亮

```markdown

```

效果: ==高亮文本==（需要主题支持）

### 4.4 文本样式

```markdown
**粗体**
*斜体*
***粗斜体***
~~删除线~~
```

效果：
- **粗体**
- *斜体*
- ***粗斜体***
- ~~删除线~~

```markdown
==**重要且高亮**==
~~*已删除且斜体*~~
```

## 6. 常见问题

### Q1：标签和链接有什么区别？

| 特性 | 标签 `#` | 链接 `[[]]` |
|------|---------|-------------|
| 用途 | 分类标记 | 文档关联 |
| 层级 | 支持多级 | 支持标题/段落 |
| 搜索 | 标签面板 | 反向链接 |
| 可视化 | 无 | 关系图谱 |

**使用建议**：
- 用**标签**标记笔记的类型、状态、优先级
- 用**链接**建立笔记之间的关联关系

### Q2：什么时候用链接，什么时候用嵌入？

**使用链接 `[[]]`**：
- 想跳转到其他笔记
- 避免内容重复
- 保持文档简洁

**使用嵌入 `![[]]`**：
- 需要在当前文档中展示其他内容
- 创建汇总文档
- 重复使用相同内容（如模板、定义）

### Q3：如何快速插入链接？

1. **输入 `[`**：自动触发链接建议
2. **输入标题**：自动创建链接
3. **快捷键**：
   - `Ctrl/Cmd + K`：插入链接
   - `Ctrl/Cmd + Shift + K`：删除链接

### Q4：Callout 在哪些主题下显示正常？

大多数现代主题都支持 Callout，包括：
- Minimal Theme ✅
- AnuPpuccin Theme ✅
- Things Theme ✅
- Default Theme ✅

如果显示异常，检查主题是否已更新到最新版本。
