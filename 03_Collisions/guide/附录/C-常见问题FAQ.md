## 安装与配置

### Q1：Obsidian 是免费的吗？

**A**：是的，Obsidian 个人使用完全免费。商业用途需要付费授权。

### Q2：如何同步数据？

**A**：多种方式
- **官方同步**：Obsidian Sync（付费）
- **第三方同步**：iCloud、Dropbox、OneDrive、坚果云
- **Git 同步**：使用 obsidian-git 插件

### Q3：如何备份知识库？

**A**：推荐方式
1. **Git 版本控制**：最推荐，可追溯历史
2. **云同步**：自动备份到云端
3. **定期导出**：导出为 Markdown 或 PDF

### Q4：迁移到新电脑？

**A**：步骤
1. 复制 `.obsidian` 文件夹
2. 复制所有笔记文件
3. 在新电脑安装 Obsidian
4. 打开知识库文件夹

## 功能使用

### Q5：如何快速创建笔记？

**A**：多种方式
- 快捷键：`Ctrl/Cmd + N`
- 命令面板：`Ctrl/Cmd + P` → "Create new note"
- 使用模板：Templater 或 QuickAdd

### Q6：如何搜索笔记？

**A**：三种方式
- **全局搜索**：`Ctrl/Cmd + Shift + F`
- **当前文件搜索**：`Ctrl/Cmd + F`
- **反向链接**：查看引用当前笔记的其他笔记

### Q7：如何使用双链？

**A**：创建链接
- `[[笔记名]]`：链接到笔记
- `[[笔记名|别名]]`：使用别名
- `![[笔记名]]`：嵌入笔记内容
- `[[笔记名#标题]]`：链接到章节

### Q8：如何使用标签？

**A**：创建标签
- `#标签名`：单个单词标签
- `#标签/子标签`：层级标签
- 在文本或 frontmatter 中使用

### Q9：如何创建目录？

**A**：自动生成
```markdown
	```dataview
	LIST
	FROM [[当前文件]]
	WHERE file
	```
```

## 插件问题

### Q10：插件无法启用？

**A**：检查步骤
1. 确认关闭安全模式
2. 检查插件版本兼容性
3. 重启 Obsidian
4. 查看控制台错误信息

### Q11：Obsidian Git 无法提交？

**A**：常见原因
- **未初始化 Git**：运行 `git init`
- **未配置远程**：运行 `git remote add`
- **认证失败**：配置 SSH 密钥
- **网络问题**：检查网络连接

### Q12：Templater 模板不生效？

**A**：检查配置
1. 确认模板文件夹路径正确
2. 检查模板语法是否正确
3. 确认 Templater 已启用
4. 查看控制台错误

### Q13：Dataview 查询出错？

**A**：常见问题
- **语法错误**：检查查询语法
- **路径问题**：使用相对路径
- **权限问题**：确保有读取权限

## 协作问题

### Q14：如何与团队共享知识库？

**A**：推荐方式
1. **使用 Gitea/GitHub**：Git 版本控制
2. **配置访问权限**：私有仓库
3. **建立协作规范**：统一的命名和流程
4. **定期同步**：避免冲突

### Q15：如何处理 Git 冲突？

**A**：解决步骤
1. 拉取最新代码
2. 查看冲突标记
3. 选择保留内容
4. 解决冲突
5. 提交修改

### Q16：团队成员看不到更新？

**A**：检查步骤
1. 确认已推送修改
2. 团队成员执行 `git pull`
3. 检查网络连接
4. 查看权限配置

## 性能问题

### Q17：Obsidian 卡顿怎么办？

**A**：优化建议
1. **关闭不必要的插件**
2. **减少大文件**：拆分大文件
3. **优化图片**：压缩图片大小
4. **清理缓存**：删除 `.obsidian/workspace`

### Q18：启动速度慢？

**A**：优化方法
1. **禁用部分插件**：特别是重型插件
2. **清理工作区**：删除 `.obsidian/workspace/mobile.json`
3. **减少核心插件**：禁用不需要的
4. **优化系统资源**：关闭其他应用

### Q19：搜索速度慢？

**A**：优化建议
1. **使用 Omnisearch**：更快的搜索插件
2. **缩小搜索范围**：指定文件夹
3. **清理无用文件**：删除临时文件
