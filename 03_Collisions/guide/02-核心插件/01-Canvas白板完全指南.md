## 1. Canvas 基础

### 1.1 什么是 Canvas

**Canvas** 是 Obsidian 内置的无限白板功能，类似于 Miro、Figma 等白板工具。

**核心特点**：
- ✅ **无限画布**：无边界限制的自由创作空间
- ✅ **多媒体支持**：嵌入笔记、图片、网页、视频
- ✅ **智能连接**：节点之间的关系可视化
- ✅ **双向链接**：白板与笔记的深度集成
- ✅ **内置功能**：无需安装插件，开箱即用

### 1.2 创建 Canvas

**方式一：命令面板**
1. 按 `Ctrl/Cmd + P` 打开命令面板
2. 输入 "Canvas"
3. 选择"创建新 Canvas"

**方式二：新建文件**
1. 点击新建文件图标
2. 选择 "Canvas" 文件类型
3. 输入文件名

**方式三：快捷键**
1. 在文件列表中按 `C`
2. 选择 Canvas 类型

## 2. Canvas 核心功能

### 2.1 添加内容

#### 文本卡片

1. 点击 Canvas 空白处
2. 选择 "文本卡片"
3. 输入内容

**快捷键**：
- 点击空白处：`T`
- 拖拽移动：选中后拖动

#### 笔记卡片

1. 点击 Canvas 空白处
2. 选择"笔记"
3. 搜索并选择笔记

**快捷键**：`[`
- 输入笔记名称搜索
- 支持拖拽文件

#### 图片

**方式一：拖拽**
- 直接拖拽图片到 Canvas

**方式二：插入**
- 点击空白处 → "图片"
- 选择图片文件

**快捷键**：点击空白处后输入 `/image`

#### 网页

1. 点击空白处
2. 选择"网页"
3. 输入 URL

**快捷键**：输入 `/web`

### 2.2 连接卡片

**创建连接**：
1. 将鼠标悬停在卡片边缘
2. 等待出现圆点
3. 从圆点拖拽到另一个卡片

**连接类型**：
- **实线箭头**：单向关联
- **虚线箭头**：弱关联
- **实线**：紧密关联
- **无箭头**：仅连接

### 2.3 组织内容

#### 分组

1. 框选多个卡片
2. 右键 → "分组"
3. 拖拽整组

**取消分组**：
- 右键组 → "取消分组"

#### 颜色编码

1. 右键卡片
2. 选择"更改颜色"
3. 选择预设颜色

## 3. 高级技巧

### 3.1 快捷键大全

| 操作 | 快捷键 |
|------|--------|
| 添加文本卡片 | `T` |
| 添加笔记 | `[` |
| 添加图片 | `/image` 或 `Ctrl/Cmd + 拖拽` |
| 添加网页 | `/web` |
| 缩放 | `Ctrl/Cmd + 滚轮` |
| 平移 | 空格 + 拖拽 |
| 选中多个 | `Shift + 点击` 或框选 |
| 删除选中 | `Delete` / `Backspace` |
| 复制 | `Ctrl/Cmd + D` |
| 粘贴 | `Ctrl/Cmd + V` |
| 撤销 | `Ctrl/Cmd + Z` |

### 3.2 嵌入预览

**笔记嵌入**：
```markdown
![[笔记名]]  <!-- 在 Canvas 中显示笔记预览 -->
```

**嵌入方式**：
1. 拖拽笔记到 Canvas
2. 选择嵌入方式
3. 设置嵌入高度

**嵌入高度调整**：
- 拖拽嵌入内容下边缘
- 或在设置中指定高度

### 3.3 样式定制

**字体大小**：
- 文本卡片：右键 → 改变字体大小
- 快捷键：`Ctrl/Cmd + 数字键`

**卡片大小**：
- 拖拽卡片右下角
- 自动适应内容

**卡片形状**：
- 右键卡片 → 样式
- 选择预设形状

### 3.4 导出功能

**导出为图片**：
1. 右键空白处
2. "导出为图片"
3. 选择分辨率

**导出为 Markdown**：
- 右键空白处
- "导出为 Markdown"

## 6. 常见问题

### Q1：Canvas 文件很大怎么办？

**A**：
- Canvas 文件通常是文本格式，不会太大
- 如果嵌入了大量图片，文件会变大
- 解决：使用外部图片链接，不嵌入图片

### Q2：如何在移动设备使用 Canvas？

**A**：
- Obsidian Mobile 支持 Canvas
- 触控操作与桌面端类似
- 建议使用平板或大屏手机

### Q3：可以导出为其他格式吗？

**A**：
- 导出为图片（PNG/PDF）
- 导出为 Markdown（列表格式）
- 第三方工具：Canvas to Markdown 插件

### Q4：Canvas 和 Excalidraw 有什么区别？

**A**：

| 特性 | Canvas | Excalidraw |
|------|--------|-------------|
| **类型** | 内置功能 | 内置插件 |
| **用途** | 组织内容 | 手绘图形 |
| **特点** | 结构化 | 自由绘图 |
| **推荐** | 项目管理 | 示意图 |
