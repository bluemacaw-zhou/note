# 03_Collisions · 碰撞实验

> 当 `01_Curiosities` 的兴趣撞上 `02_Spheres` 的职责，实验在这里发生。
> 这里的每一个实验都必须有始有终。拖延不是失败，但必须被正视。

---

## 核心要求

- **连续性**：每次推进后必须更新进度，不允许长时间无响应
- **不许烂尾**：要么完成，要么形成阶段性成果，要么写明终止原因
- **过程即价值**：报错、犹豫、走弯路都要记录，这是最高密度的知识
- **定期提醒**：超过 7 天未更新的实验，视为需要主动审视

---

## 实验状态

| 状态 | 含义 |
|------|------|
| 🔥 进行中 | 活跃推进，有明确下一步 |
| ⏸️ 阻塞中 | 遇到障碍，已记录原因，等待解除 |
| 🏁 已完成 | 达成目标，精华已回流 `01_Curiosities` |
| 🗃️ 已归档 | 无法继续，原因已记录，移入 `04_Chronicles` |
