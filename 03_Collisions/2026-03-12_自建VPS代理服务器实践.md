# 自建 VPS 代理服务器实践

## 1. 整体架构

```
本机 Clash → VPS（境外）→ 目标网站
              ↑
         Xray 服务端
         伪装成正常 HTTPS 流量
```

核心思路：在境外 VPS 上运行一个代理服务端，本机 Clash 通过加密协议与之通信。

---

## 2. 选择 VPS

推荐优先考虑的地区（延迟低、稳定性好）：
- 日本（东京）
- 新加坡
- 香港（价格较高）

推荐服务商：
- **Vultr**：按小时计费，最低 $6/月，支持支付宝
- **搬瓦工（BandwagonHost）**：CN2 GIA 线路，对国内优化好，稍贵
- **Hetzner**：欧洲节点，价格便宜，适合不在意延迟的场景

最低配置即可：**1 核 1G 内存 20G SSD**，带宽选择 1Gbps 共享。

## 3. 服务端搭建（推荐 Xray + VLESS + Reality）

### 3.1 为什么选 VLESS + Reality

- Reality 是目前最难被识别的伪装方案：它直接借用真实网站的 TLS 证书指纹，流量特征与正常 HTTPS 完全一致
- 不需要自己申请域名和证书

### 3.2 安装 Xray

SSH 登录 VPS 后执行官方一键脚本：

```bash
bash -c "$(curl -L https://github.com/XTLS/Xray-install/raw/main/install-release.sh)" @ install
```

### 3.3 生成 Reality 所需密钥对

```bash
xray x25519
```

输出示例：
```
Private key: <your-private-key>
Public key:  <your-public-key>
```

### 3.4 生成 UUID

```bash
xray uuid
```

### 3.5 配置 Xray 服务端

编辑 `/usr/local/etc/xray/config.json`：

```json
{
  "inbounds": [
    {
      "port": 443,
      "protocol": "vless",
      "settings": {
        "clients": [
          {
            "id": "<your-uuid>",
            "flow": "xtls-rprx-vision"
          }
        ],
        "decryption": "none"
      },
      "streamSettings": {
        "network": "tcp",
        "security": "reality",
        "realitySettings": {
          "dest": "www.apple.com:443",
          "serverNames": ["www.apple.com"],
          "privateKey": "<your-private-key>",
          "shortIds": [""]
        }
      }
    }
  ],
  "outbounds": [
    {
      "protocol": "freedom"
    }
  ]
}
```

> `dest` 填一个真实的境外 HTTPS 网站，Xray 会借用它的 TLS 握手特征。

### 3.6 启动服务

```bash
systemctl enable xray
systemctl start xray
systemctl status xray
```

## 4. 客户端配置（Clash）

在 Clash 配置文件的 `proxies` 部分添加：

```yaml
proxies:
  - name: "my-vps"
    type: vless
    server: <your-vps-ip>
    port: 443
    uuid: <your-uuid>
    flow: xtls-rprx-vision
    tls: true
    servername: www.apple.com
    reality-opts:
      public-key: <your-public-key>
      short-id: ""
    network: tcp
```

## 5. 防火墙配置

VPS 上需要放行 443 端口：

```bash
# Ubuntu/Debian (ufw)
ufw allow 443/tcp
ufw enable

# CentOS (firewalld)
firewall-cmd --permanent --add-port=443/tcp
firewall-cmd --reload
```

## 7. 常见问题

| 问题 | 原因 | 解决 |
|------|------|------|
| 连接超时 | 防火墙未放行端口 | 检查 ufw/iptables |
| 速度慢 | VPS 地区选择不佳或线路差 | 换 CN2 GIA 线路节点 |
| 被封 IP | 流量特征被识别 | 换端口或换协议为 Reality |
| kubectl 超时 | 本地流量走了代理 | 配置 `no_proxy` 环境变量 |
