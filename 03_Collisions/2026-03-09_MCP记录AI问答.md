# MCP 记录 AI 问答并提交 GitHub

## 目标
构建跨平台的 AI 知识归档系统，统一记录多端 AI 对话（CLI / Web / App）并自动提交到 GitHub。

---

## 核心碰撞点

**痛点**：多端 AI 对话记录零散，难以沉淀。

**架构演进**：
- 初期想法：各端分别采集
- 优化思路：利用 MCP（Model Context Protocol）作为统一接口
- 后端抉择：跳过本地文件限制，直连 GitHub API
- 定位：GitHub 是数据库，Obsidian 只是其中一个展示终端

---

## 关键洞见

- 笔记系统的价值不在于"存储"，而在于"碰撞"的过程
- AI 不应只是回答者，而应是自动化的"首席记录官"
- 统一使用 MCP 可以消除不同 AI 客户端（Claude Code / OpenCode 等）之间的行为差异

---

## 已有基础

- `sync_to_github.py`：已实现直连 GitHub API 的 commit 逻辑（blob → tree → commit → ref）
- `README.md`：AI 分类指南，MCP 归档时读取此文件确定归档路径
