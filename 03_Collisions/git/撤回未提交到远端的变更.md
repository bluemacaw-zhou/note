在Git中撤回所有本地未提交到远端的提交有几种方法，根据你的需求选择：

## 方法1：完全重置到远程分支状态（慎用）
```bash
git reset --hard origin/main
```
- 这会**彻底删除**所有本地提交和修改
- 将本地分支完全重置到远程分支的状态
- **注意：所有未提交的更改都会丢失**

## 方法2：撤销提交但保留文件修改
```bash
git reset --soft origin/main
```
- 撤销本地提交，但保留所有文件修改
- 修改的文件会回到暂存区状态
- 适合重新整理提交的场景

## 方法3：撤销提交和暂存，但保留工作目录修改
```bash
git reset --mixed origin/main
```
或简写为：
```bash
git reset origin/main
```
- 撤销提交和暂存，但保留工作目录中的文件修改
- 文件修改会变成未暂存状态

## 查看本地超前多少个提交
在执行重置前，可以先查看：
```bash
git log --oneline origin/main..HEAD
```
这会显示本地比远程多出的提交。

## 注意事项
- 将 `origin/main` 替换为你实际的远程分支名（如 `origin/master`、`origin/develop` 等）
- 执行前建议先用 `git stash` 保存重要的未提交更改
- 如果不确定，可以先创建一个备份分支：`git branch backup-branch`

选择哪种方法取决于你是否需要保留本地的修改内容。
