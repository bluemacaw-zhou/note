## 添加新的远端仓库地址

```shell
# 设置一个叫github的远端仓库
git remote add github https://github.com/bluemacaw-zhou/thinkInJava.git

# 推送本地分支到github仓库的master分支
git push -u github master
```

## 重命名现有的远端地址

```shell
# 将现有的origin的远端仓库命名为gitee
git remote rename origin gitee
```

## 删除远端仓库地址

```shell
git remote rm github
```

## 查看远端仓库地址配置

```shell
git remote -v
```
