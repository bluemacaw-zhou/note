## 运作方式

- **周期性分配时间**：每个圈层按节奏（周/月）主动分配学习或复盘时间
- **日记形式**：每次记录是独立的，时间戳 + 本次 Todo + 本次感悟
- **不强求系统性**：碎片理解的积累本身就是价值，不必强行串成体系
- **触发碰撞**：当某个职责命题需要从 `01_Curiosities` 借力时，转入 `03_Collisions`
- **周期蒸馏**：定期审视 `03_Collisions` 已完成的实验，主动分配时间提炼精华写入 `04_Chronicles`
