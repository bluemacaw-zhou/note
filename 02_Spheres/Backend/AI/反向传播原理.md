# 反向传播原理

## 什么是反向传播？

**反向传播（Backpropagation）**是训练神经网络的核心算法，用于计算损失函数对网络中每个参数的梯度。

### 工作流程

1. **前向传播**：输入数据通过网络层层计算，得到预测结果
2. **计算损失**：比较预测值和真实值，计算误差
3. **反向传播**：从输出层开始，利用链式法则逐层向前计算每个参数的梯度
4. **更新参数**：根据梯度调整权重，减小误差

### 数学基础

依赖**链式法则**：就像多米诺骨牌，前面的变化会一层层传递到后面，反向传播就是反过来追溯每一层的影响。

## 反向传播调整什么？

### 调整的参数
- **w（权重）**：连接层之间的权重矩阵
- **b（偏置）**：每层的偏移量

### 不调整的值
- **a（激活值）**：这是计算结果，不是参数

### 三个计算值的用途

反向传播会计算三个值，但用途不同：

1. **权重 w 和偏置 b 的调整量**：用来更新参数
   - 根据"调整方向"和"学习速度"来更新
   - 就像调音乐的旋钮，往哪个方向转、转多少

2. **上一层激活值的影响**：不用来更新，而是用来**继续向前传播**
   - 像接力棒一样，传递给更前面的层
   - 让前面的层知道它们该怎么调整

## 为什么每层都要调整？

### 核心理解：不是"谁的错"，而是"谁都能帮忙"

误差是**所有层共同造成的**，不是某一层单独的问题。

### 调整量的真正含义

计算出的调整量不是说"这层有错"，而是说：
> "如果我调整这一层的参数，能让最终结果改进多少"

- 调整量大 = 这层调整的"杠杆效应"大
- 调整量小 = 这层调整对结果影响小

### 类比：接力赛

接力赛输了，不能说"只怪最后一棒"：
- 每一棒都可以跑得更快
- 每个人都调整，团队才能整体提升

**协同优化**才是关键：所有层一起调整，找到全局最优的参数组合。

## 为什么需要深度网络？

### 理论 vs 实践

**万能近似定理**：单隐藏层网络理论上可以拟合任何连续函数。

**但实际问题**：参数量会爆炸。

### 深度的优势：层次化表示

**浅层网络**（输入→隐藏层→输出）：
- 需要直接从原始输入 → 最终输出
- 必须学习所有可能的组合模式
- 可能需要百万甚至亿级的神经元

**深层网络**（多个中间层）：
```
像素 → 边缘检测 → 纹理/形状 → 局部特征 → 物体部件 → 完整物体
```
- 每层负责一个抽象级别
- 用更少的参数表达更复杂的函数

### 现实世界本身就是层次化的

- 文字 = 笔画 → 偏旁 → 字 → 词 → 句子
- 音乐 = 音符 → 和弦 → 乐句 → 旋律
- 物体 = 边缘 → 纹理 → 部件 → 整体

**深度网络模仿了这种层次结构**。

### 类比：做菜

**浅层方式**：直接记住"食材 → 成品菜"的所有可能组合
- 需要记住海量的配方

**深层方式**：分步骤处理
- 第1步：处理食材（洗、切）
- 第2步：初步烹饪（炒、煮）
- 第3步：调味装盘

**分步骤更简单，需要记住的规则更少**。
