# 手写 ChatGPT 第 03 课：训练如何更新参数

**训练的核心是：当前参数先产生预测，再计算损失，沿计算关系求出梯度，最后由优化器更新参数。** 预测错了不会自动变好；只有更新参数，下一次计算才可能得到不同结果。

本课用 `y=wx` 演示这条训练骨架。它不是完整语言模型，但能把“学习”还原为可以手算的参数变化。笔记根据第 3 个视频的 Whisper 字幕，并对照语雀《大模型是怎么学会的》整理；修订口语简化和数值不一致处，不把教材类比当作严格定义。

## 1. 一轮训练里，哪些步骤在做什么

| 步骤 | 用人学习做类比 | 在程序中的实际含义 |
|---|---|---|
| 准备数据 | 取得题目与参考答案 | 输入 X 和真实标签 Y |
| 前向传播 | 尝试答题 | 当前参数 W 产生预测 Y_pred |
| 计算损失 | 对照答案评价表现 | 把预测和标签代入损失函数，得到标量 loss |
| 反向传播 | 分析怎样调整 | 根据链式法则计算 loss 对参数的导数 |
| 参数更新 | 修改原有理解 | 优化器根据梯度和学习率修改 W |
| 再次计算 | 再做一次题 | 用更新后的参数重新预测、评价 |

类比只帮助理解顺序，不能据此认为深度学习与生物学习完全相同。

```text
当前 W → 预测 → 误差/损失 → 梯度 → 更新 W
   ↑                                 │
   └──────── 下一轮使用新 W ──────────┘
```

**前向传播负责算答案，反向传播负责算梯度，优化器负责改参数。** 后两步不是同一件事。推理通常只走预测过程，不根据用户每次提问自动修改权重。

## 2. 用同一组数据理解误差、损失和梯度

视频的目标是让模型从数据学出 `y=3x`。我们只把训练输入和答案给模型，不直接把正确系数 3 写入它的参数。

```text
X = [1, 2, 3, 4, 5]
Y = [3, 6, 9, 12, 15]
模型：Y_pred = w × X
初始 w = 0.55（为方便手算取整，不是声称视频精确初值）
```

### 先预测，再算误差

| x | 真实 y | 当前预测 wx | error = wx − y |
|---:|---:|---:|---:|
| 1 | 3 | 0.55 | −2.45 |
| 2 | 6 | 1.10 | −4.90 |
| 3 | 9 | 1.65 | −7.35 |
| 4 | 12 | 2.20 | −9.80 |
| 5 | 15 | 2.75 | −12.25 |

这里的 `error` 是各样本的带符号差值。用均方误差（MSE）把它们汇总成损失：

$$L(w)=\frac{1}{N}\sum_{i=1}^{N}(wx_i-y_i)^2$$

`N=5` 是样本数，`x_i/y_i` 是第 i 个输入/真实答案。代入 `w=0.55` 得到：

$$L(0.55)=66.0275$$

损失函数是上面的规则，损失是本次算出的 `66.0275`。这个数只描述按该规则评价的预测表现，不能单靠它推出每个参数应该怎样改变。

### 梯度是损失对参数的变化率

$$\frac{dL}{dw}=\frac{2}{N}\sum_{i=1}^{N}(wx_i-y_i)x_i$$

代入同一组数据：

$$\frac{dL}{dw}\bigg|_{w=0.55}=-53.9$$

`66.0275` 是损失，`−53.9` 是梯度。两者不是一个东西：梯度表示在当前参数附近，w 改变时损失怎样变化，并非“错了多少”的另一个名字。

### 学习率决定沿梯度走多远

普通梯度下降使用：

$$w_{new}=w-\eta\frac{dL}{dw}$$

`η` 是正的学习率。取 `η=0.01`：

$$w_{new}=0.55-0.01\times(-53.9)=1.089$$

再次前向计算，损失变为 `40.171131`，比之前小。这一步并没有直接得到 3，但参数已沿让损失下降的方向移动。

上述数字为整理时重新计算的教学例子，不是重新训练视频模型得到的日志。

## 3. 为什么叫“梯度下降”，参数却可能增大

“下降”说的是**期望降低损失**，不是要求参数数值下降。

对于正学习率下的普通梯度下降：

- 当前梯度为负：减去负数，w 增大。
- 当前梯度为正：减去正数，w 减小。
- 多参数情况下，各参数根据自己的偏导数分别更新。

梯度符号描述的是损失对参数的局部变化，不能普遍解释为“预测值小了/大了”。在本例所有 x 为正且只有一个参数时，两者容易对应；换成复杂网络就不能这样直接判断。

梯度下降也不等于机器学习中特指的“微调（fine-tuning）”。微调通常指在已有训练权重上继续训练；此处说的是更一般的参数更新。

步长过大可能越过低损失区域，让损失反而上升；重复训练也不保证必然得到正确答案或泛化能力。`loss < 0.002` 是视频针对教学实验给的经验描述，不能当成任何任务的统一合格线，应结合损失定义、数据尺度、验证数据和实际预测效果判断。

## 4. 链式法则怎样连接预测和参数

前向计算可以拆成：

$$w\rightarrow \hat y_i=wx_i\rightarrow e_i=\hat y_i-y_i\rightarrow L=\frac{1}{N}\sum e_i^2$$

反向沿依赖关系计算各个局部导数：

$$\frac{\partial L}{\partial e_i}=\frac{2e_i}{N},\quad
\frac{\partial e_i}{\partial\hat y_i}=1,\quad
\frac{\partial\hat y_i}{\partial w}=x_i$$

把三段相乘，并累加所有样本对共享参数 w 的贡献，就得到前面的 `dL/dw`。均值损失含有 `1/N`，所以梯度也需要相应的平均；不是写完梯度后随意再除一次。

在神经网络中，同样沿计算依赖关系求导，只是层数更多、参数是矩阵。数学中多个参数的偏导数组成梯度，反向传播是高效计算这些梯度的过程。

## 5. 对照视频和当前代码

线性例子的训练骨架可以写成：

```python
# 说明性代码：与上文数据、MSE 定义保持一致。
X = np.array([1, 2, 3, 4, 5], dtype=float)
Y = 3 * X
w = 0.55
lr = 0.01

for epoch in range(100):
    Y_pred = w * X
    error = Y_pred - Y
    loss = np.mean(error ** 2)
    dw = np.sum((2 * error / len(X)) * X)
    w -= lr * dw
```

此片段需先 `import numpy as np`。loss 是本轮更新**前**参数的评价，更新后若要知道新 loss，应重新前向计算。

当前项目把同样的职责拆为：

```text
optimizer.zero_grad()     清除上一轮梯度
model.forward(X_ids)     计算概率
CrossEntropyLoss(...)    评价真实下一 token 的概率
model.backward(...)      手动计算各层梯度
optimizer.step()         用 SGD 更新 Parameter.data
```

`y=wx` 使用 MSE；当前字符预测使用交叉熵，二者的损失公式不同，但“预测 → 损失 → 梯度 → 更新”的组织方式相同。Embedding 表、Attention 投影和 LM Head 都可以是这条链上被训练的参数。

第 2 课 [[2026-10-29_手写ChatGPT第02课_预测Token的数据流]] 说明这些层怎样产生预测；本课补上它们的参数怎样学习，而不是在训练前另做一次“先把 Embedding 学好”的独立流程。

## 6. 语雀参考材料中的两处修订

参考笔记的单样本条件是 `x=2，y_true=10，w=3`。因此：

$$\hat y=6,\quad e=-4,\quad L=e^2=16$$

但按这些条件，真正的梯度应为：

$$\frac{dL}{dw}=2(wx-y)x=2(-4)\times2=-16$$

原文接着写的 `dW≈−53.9261` **不能从这组单样本条件推得**，可能混用了另一个批量例子的结果；本笔记不沿用该数字。若选学习率 `0.1`，一步得到 `w_new=4.6`，重新算出的损失为 `0.64`，而不是不交代学习率就断言直接到达 5。

原文“求导，就是 w 等于某个值时 Loss 的值”也应修正：`L(w)` 才是在该 w 下的损失值，`dL/dw` 是它在该处对 w 的局部变化率。原文后面的“变化一点会引起多少变化”更接近导数含义。
