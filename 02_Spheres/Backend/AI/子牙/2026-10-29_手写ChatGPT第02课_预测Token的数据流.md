# 手写 ChatGPT 第 02 课：预测 Token 的数据流

本课回答的是：**输入一段文字之后，Tokenizer、Embedding、Transformer、LM Head 和 Softmax 怎样配合，得到下一个 token？** 先把整条计算管线串起来，再深入每个模块，比孤立记名词更容易理解。

本篇按概念整理第 2 个视频的 Whisper 字幕，删去重复口语，修订明显识别错误。下文的数值例子用于解释，除特别说明外不作为视频训练日志。课程讲解的是教学模型，不能直接据此断言所有大模型的内部实现。

## 1. 从文本到下一 Token：每个模块负责什么

沿用课程中的字符级例子：输入“你是谁”，希望模型接着生成“我是子牙……”。

```text
“你是谁”
    ↓ Tokenizer.encode：按词表转换
整数 token ID
    ↓ Embedding：根据 ID 查向量表
每个 token 的特征向量
    ↓ 加入位置向量
带位置信息的输入向量
    ↓ 多层 TransformerBlock
融合上下文的隐藏状态
    ↓ LM Head：投影到词表大小
每个候选 token 的原始分数 logits
    ↓ Softmax
下一 token 的概率分布
    ↓ 选择 token ID，再 decode
“我”
```

| 模块 | 输入 → 输出 | 负责解决的问题 |
|---|---|---|
| Tokenizer | 文本 → ID；ID → 文本 | 文字怎样进入数值计算、怎样还原成文字 |
| Embedding | ID → D 维向量 | 用可训练的稠密数值表示每个 token |
| 位置编码 | token 向量与位置 → 输入表示 | 给模型提供顺序信息 |
| TransformerBlock | 输入表示 → 隐藏状态 | 结合上下文变换表示 |
| LM Head | 隐藏状态 → V 个分数 | 把内部特征转换成词表候选的分数 |
| Softmax | 分数 → 概率 | 把候选分数归一化为概率分布 |

`V` 是词表大小，`D` 是向量维度，二者不是同一个量。课程举的 `V=273` 是该教学词表的大小，不是语言模型固定值。

Transformer 是一种网络架构，TransformerBlock 是其中可重复堆叠的结构单元。不能简单把两者定义成“理论”和“实现”；完整语言模型还需要输入表示、输出头等组件，聊天产品还包含外围交互系统。

## 2. Token ID、Embedding 与隐藏状态的区别

### ID 是编号，不是含义的大小

假设“我”的 ID 是 53，它只表示“查词表第 53 项”。不能由此认为“我”比 ID 为 2 的字符语义更大，也不能把两个 ID 的差当作语义距离。

本项目按字符切分。其他 tokenizer 可以把一个词或多个字符作为 token；字幕中关于“我是子牙老师”切成若干 token 的展示属于特定分词器示例，切分结果取决于词表和编码规则。

### Embedding 是一张可训练的表

若 `V=273`、`D=4`，Embedding 表的形状就是 `(273,4)`。输入 ID=53，就取第 53 行的四个数。

- 从零训练时，这张表先随机初始化；同一个 ID 始终指向同一行。
- 训练会更新表中的向量，使其有助于完成预测任务；不要求一开始就具有语义。
- 一般不能把某一坐标直接解释成一个固定的人类概念。

位置向量描述“它在窗口中的哪个位置”，token 向量描述“它是哪个 token 的可训练表示”。本项目使用二者相加的可训练绝对位置编码。RoPE 是另一种位置处理方法，作用于注意力中的 Q/K，不等同于再加一张位置表。

### 隐藏状态是经过上下文加工后的表示

同一个“我”查表取得的初始 token 向量相同；经过 Transformer 后，它的隐藏状态会受到上下文影响。输入和输出可以维度相同，但数值和包含的信息不同。

## 3. Attention、多头和掩码为什么出现在这条管线里

Attention 让一个位置按权重汇集其他位置的信息。Q/K/V 分别参与匹配与内容汇集，多头则在不同的投影子空间中并行计算。

在本项目等宽拆头的实现里，必须满足：

$$D=H\times D_h$$

`H` 是头数，`D_h` 是每个头的维度。例如 `D=4,H=2`，每头处理 2 维；固定为两头时，`D=5` 无法按这里的规则均分。不是说“5 维向量永远不合法”，而是要与具体注意力实现匹配。

**因果掩码**让位置 i 只能看自己及更早的位置，不能读取窗口中排在它后面的 token，避免下一 token 预测时使用未来信息。训练需要真实答案来计算损失；“不能看答案”指不能把不该看到的未来内容泄露进对应预测位置，并非训练时没有标签。

残差连接、LayerNorm 和 FFN 负责信息与梯度通路、特征归一化、逐位置非线性变换。本课先知道它们在管线中的位置，不必一次推导全部公式。

## 4. 得到概率之后，怎样变成一句话

假设词表有 273 项，某一步输出 `(1,273)` 的概率向量。索引与词表一一对应，例如第 53 项对应“我”。如果采用**贪心解码**，就选择概率最大的 ID：

```text
输入“你是谁” → 选出“我”
输入“你是谁我” → 选出“是”
输入“你是谁我是” → 继续预测
…… → 选出 EOS → 停止
```

这就是自回归：**把已生成的 token 加入上下文，再预测下一项。** 当前项目每次实际取最后 `context_len` 个 token 作为输入；不是生成越长，每次传入的窗口就无限变长。

EOS 是训练数据构造时加入的特殊结束标记，模型通过训练学习何时预测它。程序也可以设置最大生成长度，防止一直不输出 EOS。

需要纠正课程口语化表述：

- “永远选择最大概率”只描述这里的贪心策略；采样策略不一定选择最大项。
- 正确答案不一定只有一种。多个候选概率较大不自动说明训练失败。
- 上下文更长能提供更多信息，但不保证每次预测更准确。
- “预测 token”描述生成机制，不能单靠这个机制判定模型是否具有智能；本课无需对这种争论下结论。

## 5. 与当前项目对照

当前 `pytorch/Model.py` 的路径为：

```text
整数 ID (B,T)
→ Embedding + PositionEmbedding (B,T,D)
→ 四个独立 TransformerBlock (B,T,D)
→ 取最后位置 (B,D)
→ Linear / LM Head (B,V)
→ Softmax (B,V)
```

`B` 是批量样本数，`T` 是窗口长度。课程视频提到的模型版本是两层 block，当前代码已演进为四层，不能混为同一个版本。当前也没有把整个 `(T,D)` 展平后再分类，而是取最后位置。

本课解释的是“如何计算预测”；下一课 [[2026-10-29_手写ChatGPT第03课_训练如何更新参数]] 解释“这些可训练参数如何从随机值变得有用”。
