# 张量、分数与概率的含义

## 本次追问

“张量怎么就能够转变成概率？”“换一种任务，每条数据的概率又代表什么？”

来源：2026-10-28 bert-demo 对话；学习解释待 review。前置阅读：[[2026-10-28_BERT学习讨论索引与训练单位]]。

## 张量不是概率转换规则

张量是组织数字的数据结构。特征、类别分数、概率都可以装在张量里，但含义不同。张量不会自然变成概率，需要模型结构和指定计算。

当前管线：

```text
评论 → BERT 特征 → 分类层的两个分数 → softmax → 两个类别概率
```

分类层输出 logits，例如 [1, 2]（顺序为负面、正面）。它们是任意实数，不需要非负，也不需要加起来等于 1。

softmax 定义为：

$$p_k=\frac{e^{z_k}}{\sum_j e^{z_j}}$$

这里 e¹≈2.718、e²≈7.389；分别除以总和后得到 [0.269, 0.731]。计算前后都是张量，只是后者的数值满足类别概率的约束：非负且总和为 1。数值实现通常先减最大分数以避免指数溢出，结果不变。

## 概率对应的是问题和答案

“正面 73.1%”表示模型给定该评论后，对其属于正面类别的概率估计，不表示文字中 73.1% 是正面，也不是这次预测正确率的保证。

| 任务 | 概率所针对的事件 |
|---|---|
| 评论分类 | 这条评论属于正面或负面 |
| 图片分类 | 图片属于猫、狗等定义好的类别 |
| 垃圾邮件 | 邮件属于垃圾邮件 |
| 新闻分类 | 新闻属于体育、财经等类别 |
| 语言模型 | 给定前文，下一个词元是某个候选词元 |

不是每条数据必然只输出一个概率：序列标注可为每个词元输出类别分布，目标检测可对多个候选对象输出分数。多标签任务中几个事件可同时成立，各标签概率不必合计为 1；不能一概使用互斥类别的 softmax 思路。

也不是每种模型一定输出概率：房价回归可直接输出一个预测数值，向量模型可输出特征表示。

## 为什么满足概率形式还不等于可靠

随机初始化的分类层也能输出 softmax 数字，但不代表它知道答案。训练调整参数，使真实标签获得更合理的概率。

概率校准是另一个问题：在大量被预测为正面概率约 95% 的样本中，若实际约 95% 为正面，可认为该概率区间较校准。准确率高不保证校准好；未知领域输入也可能得到过高置信度。
