# 特征空间与词向量

> 总览 [[day03_00_总览|day03]] · ← [[day03_05_采样参数|采样参数]] · 下一块 → [[day03_07_文本分类与datasets|分类与数据集]]

**为什么需要**：791 只是「今」在词表里的行号。行号相邻的两个字，意思不一定相近；791 和 792 也没有大小、远近的含义。模型需要一种能表达「意思」的表示。

## 先看一个直观的例子：特征空间

![[procreate/特征空间赋予数据含义.png]]

**读图**：左图有「身高」和「头发长度」两条轴，A（180cm，5cm）和 B（160cm，35cm）的位置一眼就能读出含义：A 是男性的概率高，B 是女性的概率高。右图是同样的两个圈，但没有坐标轴，就什么也说明不了。

**结论**：数据只有放进对应的特征空间，才能表达含义。这正是 day01_02 讲「特征」的原因。

## 再看文字：从索引到词向量

![[procreate/从索引到词向量.png]]

**读图**：

1. 模型内部有一张**词嵌入表** `wte`，形状是 `21128 × 768`（实测），每个字占一行。
2. 索引 791 的作用，就是**取出第 791 行**：「今」= `[0.076, −0.005, 0.023, −0.026, …]`，一共 768 个数。
3. 这 768 个数就是「今」在 768 维特征空间里的坐标。

**意思相近的字，坐标也相近**（实测余弦相似度，1 表示方向完全相同）：

| 字对 | 相似度 | 说明 |
|---|---:|---|
| 男–女 | 0.63 | 同属性别 |
| 今–昨 | 0.53 | 同属时间 |
| 狗–犬 | 0.47 | 同义 |
| 狗–dog | 0.45 | **跨语言**也很接近，对应课堂笔记里写在一起的「狗 / dog」 |
| 狗–猫 | 0.42 | 同属宠物 |
| 今–狗 | −0.03 | 无关 |

**这些坐标从哪来**：嵌入表也是模型参数，和 day02 的 W 一样，是训练时用反向传播一点点调出来的。没有人告诉模型「狗」和「犬」是同义词，是大量文本让它们的坐标靠到了一起。

**一句话总结**：分词器的编号解决了「怎么输入」的问题，词向量空间里的位置才代表「是什么意思」。

**引出下一块**：同一套「分词 → 向量 → 模型」的流程，换一个输出头，就能做文本分类。
