# day03 HuggingFace 核心组件 · 总览

day01、day02 是**自己搭网络、自己训练**。day03 换了一个方向：**直接用别人训练好的模型**。HuggingFace 负责托管和下载模型，transformers 负责加载和推理。

课堂笔记顺着「一句话进入模型，一个字出来」这条链路，讲清楚了每一步在做什么。这条链路是本目录的主线。

## 主线：一句话怎样变成下一个字

```text
"今天天气"
   │ 03 分词：切成字      [今][天][天][气]
   │ 03 查表：变成索引    [791][1921][1921][3698]
   │ 06 查嵌入表：变成向量  每个字 768 个数
   ▼
GPT-2 模型
   │ 04 输出层：21128 个概率   很 0.211、不 0.109、好 0.095 …
   │ 05 采样：按 temperature / top_k / top_p 选一个
   ▼
"很"
```

## 和 day01、day02 的衔接

- 04 的「生成就是分类」，就是 day01_08 的 Softmax 多分类，只是类别数从 3 个变成了 21128 个。
- 05 的 temperature，是在 day01_08 的 Softmax 公式里给得分统一除以一个数 T。
- 06 的「特征空间」，就是 day01_02 的「特征」概念：数字只有放在有意义的坐标轴上，才能代表东西。
