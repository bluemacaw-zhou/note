# 模型下载与本地加载

> 总览 [[day03_00_总览|day03]] · ← [[day03_01_HuggingFace是什么与三种调用方式|平台与调用方式]] · 下一块 → [[day03_03_分词与索引|分词]]

**为什么需要**：本地推理要先把模型文件拿到手，而且要在不联网的情况下也能加载。

## 一行代码完成下载和加载

```python
model = AutoModelForCausalLM.from_pretrained("uer/gpt2-chinese-cluecorpussmall", cache_dir=...)
tokenizer = AutoTokenizer.from_pretrained("uer/gpt2-chinese-cluecorpussmall", cache_dir=...)
```

- `Auto*`：读取模型的 `config.json`，自动选择对应的类。`CausalLM` 表示「根据前文预测下一个字」。
- 模型和分词器**必须成对**：分词器的词表决定了编号，模型只认识这套编号。

## 下载下来的是什么

| 文件 | 内容 |
|---|---|
| `config.json` | 结构超参数，例如 `vocab_size: 21128`、`n_embd: 768`、`n_ctx: 1024` |
| `vocab.txt` | 词表，一行一个字，**行号就是索引**（见 [[day03_03_分词与索引\|03]]） |
| `tokenizer_config.json` | 分词器设置 |
| `pytorch_model.bin` / `model.safetensors` | 权重。safetensors 更安全，加载也更快 |

## 缓存目录为什么这么深

用 `cache_dir` 下载时，目录长这样：

```text
model/uer/gpt2-chinese-cluecorpussmall/
└── models--uer--gpt2-chinese-cluecorpussmall/
    ├── blobs/        真实文件，按内容哈希命名
    ├── refs/main     记录 main 分支当前指向哪个提交
    └── snapshots/
        ├── c2c0249…/ config、词表、pytorch_model.bin
        └── 684a6fb…/ model.safetensors（另一个提交）
```

每个提交对应一个 snapshot 目录，里面的文件都链接到 blobs。课程的 `test02.py` 因此只能写死一长串 snapshot 路径，而且是 Windows 绝对路径。

**我的改写**（`huggingface-demo/trsanformers_test/model_download.py`）：

| 做法 | 作用 |
|---|---|
| `snapshot_download(repo_id, local_dir=MODEL_DIR, allow_patterns=[...])` | 文件直接平铺到 `model/<repo>/`，没有多层缓存目录；只下载需要的文件 |
| 加载时传 `local_files_only=True` | 禁止联网，确认本地文件是完整的 |
| `HF_HUB_DISABLE_XET=1` | 走本机代理时 Xet 下载会报 TLS 错误，改用普通 HTTP |
| `device = 0 if torch.cuda.is_available() else -1` | Mac 没有 CUDA，自动回退到 CPU。课程代码写死了 `device="cuda"` |
