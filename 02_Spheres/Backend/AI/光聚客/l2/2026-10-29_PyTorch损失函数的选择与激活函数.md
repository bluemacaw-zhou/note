# PyTorch 损失函数的选择与激活函数

**先明确任务和标签含义，再选择输出结构与损失函数。实际调用时，关键是损失函数需要原始分数、概率，还是对数概率。** 以下讨论输出层的激活，不是隐藏层的 ReLU、GELU 等激活。

## 1. 按任务选择常用损失

| 任务与例子 | 每条数据的模型输出 | 常用损失函数 | 获得概率或结果 |
|---|---|---|---|
| 二分类：评论正面或负面，一维方案 | 一个 logit | BCEWithLogitsLoss | Sigmoid 得到正面概率，负面概率为补数 |
| 二分类：当前评论项目 | 两个 logits | CrossEntropyLoss | Softmax 得到负面、正面概率 |
| 多分类：新闻只能属于一个类别 | K 个 logits | CrossEntropyLoss | Softmax 得到总和为 1 的 K 类概率 |
| 多标签：评论可同时提到卫生、服务、价格 | K 个 logits | BCEWithLogitsLoss | 对各分数分别 Sigmoid，概率不要求总和为 1 |
| 回归：预测房价 | 预测数值 | MSELoss、L1Loss、HuberLoss 等 | 通常直接使用数值，不需要概率映射 |

分类首先区分“多个类别互斥”与“多个标签可同时成立”。回归中，MSE 平方惩罚大误差；L1 使用绝对误差；Huber 在小误差区域使用二次形式、大误差区域转为线性，对异常大误差通常比 MSE 温和。具体选择仍需结合业务代价、数据特点和验证集表现，不只看任务名称。

## 2. 哪些内含激活相关计算，哪些需要显式转换

这里“绑定”指**损失函数内部整合了对应运算**，不代表 PyTorch 自动在模型中插入一层或替开发者匹配接口。

| 损失函数 | 调用时接收什么 | 内部已整合什么 | 若模型输出原始分数，损失前是否手动转换 |
|---|---|---|---|
| CrossEntropyLoss | logits，任意实数 | LogSoftmax + NLLLoss 对应计算 | **不调用 Softmax**，直接传 logits |
| BCEWithLogitsLoss | logits，任意实数 | Sigmoid + 二元交叉熵对应计算 | **不调用 Sigmoid**，直接传 logits |
| BCELoss | 0～1 的概率 | 二元交叉熵，不含 Sigmoid | **先 Sigmoid**；如果上游已给概率，不重复转换 |
| NLLLoss | 对数概率 log(p) | 取真实类别的负对数概率等计算，不含 LogSoftmax | **先 LogSoftmax**；不是普通 Softmax |
| MSELoss / L1Loss / HuberLoss | 与目标同含义的预测数值 | 数值误差计算，不含上述激活 | 普通回归无需概率激活；输出约束由任务另行设计 |

LogSoftmax 直接计算概率的对数，并非先生成普通概率再取 log；整合计算可提高数值稳定性。Sigmoid 与 BCE 整合也比显式拆开更稳定，因此从 logits 训练时通常优先 BCEWithLogitsLoss。

**即使输入形式不匹配，有些代码仍能运行，但优化目标已经改变。不要仅以“不报错”判断搭配正确。**

## 3. 当前项目为什么没有显式 Softmax

当前分类层为 `Linear(768, 2)`，输出两个原始分数；标签为负面 0、正面 1。

```python
# logits：[批大小, 2]；labels：[批大小]，torch.long 类别编号。
logits = model(**inputs)
loss_function = torch.nn.CrossEntropyLoss()
loss = loss_function(logits, labels)  # 内部已有 LogSoftmax 对应计算

# 只需要类别时，直接取最大分数：Softmax 不改变大小顺序。
predictions = logits.argmax(dim=1)

# 需要展示概率时，才在这个分支显式转换。
probabilities = torch.softmax(logits, dim=1)
```

例如 logits 为 `[2, 7]`，Softmax 后约为 `[0.0067, 0.9933]`。真实类别为正面，单条交叉熵约为 `−ln(0.9933)=0.0067`。CrossEntropyLoss 直接从 `[2,7]` 得到损失，不需要手动把概率传进去。

```text
训练：logits + 真实标签 → CrossEntropyLoss → 损失
展示：logits → Softmax → 概率
判断类别：logits → argmax → 类别编号
```

这里的标签格式是当前硬标签分类方案；CrossEntropyLoss 也支持按文档约定传入目标类别分布，不能把它与“模型预测概率作为输入”混淆。

## 4. 需要手动转换时怎么写

下面几种写法是替代方案，不是在当前训练链中依次执行。

```python
# 二分类：同一批数据的一个原始分数 z，浮点标签 y，形状相同。
# 方案 A：整合实现，通常优先采用。
loss = torch.nn.BCEWithLogitsLoss()(z, y)

# 方案 B：分开实现，BCELoss 要求概率输入。
probabilities = torch.sigmoid(z)
loss = torch.nn.BCELoss()(probabilities, y)

# 互斥分类：整合写法与拆分写法对应。
loss = torch.nn.CrossEntropyLoss()(logits, labels)
log_probabilities = torch.log_softmax(logits, dim=1)
loss = torch.nn.NLLLoss()(log_probabilities, labels)
```

BCE 的目标一般为 0/1 浮点值，也可按任务使用 [0,1] 内的软目标；输入与目标的形状必须匹配。不要给 BCEWithLogitsLoss 重复加 Sigmoid，不要给 CrossEntropyLoss 重复加 Softmax，也不要把普通概率直接传给 NLLLoss。
