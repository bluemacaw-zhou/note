# Softmax 与交叉熵：分类问题怎么算损失

> 总览 [[day01_00_总览|day01]] · ← [[day01_07_损失代价与目标函数|损失与代价]] · 下一块 → [[day01_09_梯度下降与学习率|梯度下降]]

**为什么需要**：分类模型输出的是任意实数的得分，要先转成概率，才能用「给正确答案多少概率」来衡量好坏。

## 两步：得分 → 概率 → 损失

```text
Softmax：pₖ = e^{sₖ} / Σⱼ e^{sⱼ}
交叉熵：L = −ln p(真实类别)
```

## 例子（课件中的三分类，真实类别是 cat）

| 类别 | 得分 | exp | 概率 |
|---|---:|---:|---:|
| cat | 3.2 | 24.5 | **0.13** |
| car | 5.1 | 164.0 | 0.87 |
| frog | −1.7 | 0.18 | 0.00 |

```text
L = −ln 0.13 ≈ 2.04
```

> **勘误**：课件写的是 0.89，那是用 log₁₀ 算的（−log₁₀ 0.13 ≈ 0.89）。PyTorch 的 `CrossEntropyLoss` 用自然对数，结果是 2.04。

![[procreate/Softmax与交叉熵.png]]

**读图**：从左到右三个方框是 Softmax 的三步：原始得分 → 取 exp（全部变成正数，并放大差距）→ 除以总和（归一化，总和为 1）。真实类别 cat 只拿到 0.13（红圈），右侧红字是它的损失 `−ln 0.13 ≈ 2.04`，已按上面的勘误改成自然对数。

![[procreate/负对数损失函数.png]]

**怎么读图**：横轴是真实类别拿到的概率 p，纵轴是损失 −ln p。cat 只拿到 0.13，落在曲线左侧陡峭的部分，损失很大。p 升到 0.9 时，损失只有 0.105。

**一句话**：模型给正确答案的概率越低，惩罚越重，而且是加速变重。

**引出下一块**：损失只告诉我们错了多少，没有告诉我们 W 该往哪个方向改。
