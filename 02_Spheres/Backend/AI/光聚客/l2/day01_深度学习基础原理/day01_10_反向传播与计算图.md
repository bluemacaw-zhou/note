# 反向传播与计算图

> 总览 [[day01_00_总览|day01]] · ← [[day01_09_梯度下降与学习率|梯度下降]] · 下一块 → [[day01_11_训练流程与常用术语|训练流程]]

**为什么需要**：梯度下降需要损失对**每个参数**的导数。参数藏在很多层计算后面，要一层层往回求。

## 计算图上的链式法则（课件例子）

`f = (x + y)·z`，取 x = −2，y = 5，z = −4：

```text
前向：q = x + y = 3，      f = q·z = −12
反向：∂f/∂z = q = 3
      ∂f/∂q = z = −4
      ∂f/∂x = ∂f/∂q · ∂q/∂x = −4 × 1 = −4
      ∂f/∂y = −4
```

**怎么理解**：x 或 y 增加 1，f 变化 −4；z 增加 1，f 变化 +3。反向传播就是从输出往回，把每个节点的局部导数相乘。

![[procreate/计算图与链式法则.png]]

**读图**：线**上方的黑字**是前向时的值（−2、5 → 3 → −12），线**下方的红字**是反向传回来的梯度。读法是顺着红色箭头从右往左：`×` 节点把 q 和 z 的值互换后作为各自的梯度传回去，所以 z 拿到 3、q 拿到 −4；`+` 节点把梯度原样分给 x 和 y，所以都是 −4。右侧蓝色部分是每个节点的局部导数，以及把它们相乘的链式法则。

## 单个神经元（Sigmoid + 交叉熵）

```text
前向：z = w₁x₁ + w₂x₂ + b，a = σ(z)，L = −[y·ln a + (1−y)·ln(1−a)]
反向：dz = a − y，dw₁ = x₁·dz，dw₂ = x₂·dz，db = dz
```

`dz = a − y` 很简洁，因为 Sigmoid 的导数 `a(1−a)` 正好和交叉熵导数的分母约掉了。

## 推广到 m 个样本：矩阵化

```text
dZ = A − Y
dW = (1/m)·X·dZᵀ
db = (1/m)·Σ dZ
```

**和单样本的关系**：公式完全相同，只是把每个样本的梯度平均起来，用矩阵一次算完。
