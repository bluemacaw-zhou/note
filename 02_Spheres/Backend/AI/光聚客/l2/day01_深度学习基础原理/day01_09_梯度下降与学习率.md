# 梯度下降与学习率

> 总览 [[day01_00_总览|day01]] · ← [[day01_08_Softmax与交叉熵|交叉熵]] · 下一块 → [[day01_10_反向传播与计算图|反向传播]]

**为什么需要**：损失只给出「错了多少」，要知道参数该往哪个方向改、改多少，需要导数。

## 直觉：猜数字游戏（课件）

心里想一个 1～100 之间的数，答案是 49。每猜一次，只告诉你「大了」或「小了」：

```text
81 大了 → 71 大了 → 61 大了 → 51 大了 → 41 小了 → 45 小了 → 48 小了 → 50 大了 → 49
```

| 游戏 | 训练 |
|---|---|
| 「大了 / 小了」 | 梯度的**方向** |
| 每次跳多远 | **学习率** |
| 猜一轮 | 一次迭代 |

![[procreate/猜数字游戏.png]]

**读图**：数轴上的蓝色弧线是每次的跳跃。前 4 跳每次跳 10（81 → 41），一跨过答案（41「小了」）就掉头，此后步子缩成 4、3、2、1，最终停在绿旗 49。右侧两框是对应关系：大了 / 小了是梯度方向，跳多远是学习率。（课件最后一轮写的是「49 → 小了」，应为笔误，图中已改为猜中。）

## 公式

```text
x⁽ᵏ⁺¹⁾ = x⁽ᵏ⁾ − η · df/dx
```

一步的长度等于 `η × 斜率`。坡越陡，一步越大；接近最低点时，坡变缓，步子自然变小。

![[procreate/学习率与步长.png]]

**读图**：红色弧线是每一步的跳跃。在右上方坡陡的地方（切线陡），跳得远；越靠近底部，切线越平，跳得越短。学习率 η 不变，步长却自动变小，因为步长等于 η 乘以斜率。

## 学习率的两种失败

| η | 表现 |
|---|---|
| 太小 | 需要很多次迭代，收敛慢 |
| 太大 | 跨过最低点，来回震荡，甚至发散 |

> 实验佐证：[[02_Spheres/Backend/AI/子牙/2026-10-29_手写ChatGPT_专题一_线性模型与训练闭环|专题一]] ⑪，lr = 0.04 很快收敛；lr = 0.089 来回跨过最低点。

**和负梯度的关系**：负梯度给出方向，学习率给出步长。见 [[2026-10-29_损失与负梯度|损失与负梯度]]。
