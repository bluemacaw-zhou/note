# 多层感知机：为什么叠层必须配激活函数

> 总览 [[day01_00_总览|day01]] · ← [[day01_04_神经元与偏置|神经元]] · 下一块 → [[day01_06_常见激活函数对比|常见激活函数]]

**为什么需要**：单个神经元只能画直线，要拟合弯曲的分界线，得把多个神经元组合起来。

## 多层感知机（MLP）

```text
输入层 → 隐藏层 1 → 隐藏层 2 → … → 输出层
```

- **全连接**：上一层的每个神经元都连到下一层的每个神经元。
- **隐藏层**：中间层，它的输出不直接暴露给外部。
- **例子**：3 个输入、3 个隐藏层各 3 个神经元、2 个输出，参数量是 `(3×3 + 3) × 3 + (3×2 + 2) = 44`。

![[procreate/多层感知机结构.png]]

**读图**：这就是上面算参数量的那个网络。每一列是一层，相邻两列之间每两个圆都连了线，这就是全连接。顶部的公式 `f(Wout·f(W3·f(W2·f(w1·x+b1)+b2)+b3)+bout)` 从里往外读，就是一层套一层。注意每层外面都包了一个 **f**，也就是下文要讲的激活函数。

## 只叠层不够：线性叠线性还是线性

```text
第一层 h = w₁x + b₁
第二层 y = w₂h + b₂ = (w₂w₁)x + (w₂b₁ + b₂)
```

合起来**还是一条直线**。叠多少层，表达能力都等于一层。

> 实验佐证：[[02_Spheres/Backend/AI/子牙/2026-10-29_手写ChatGPT_专题一_线性模型与训练闭环|专题一]] ⑩，两层线性模型最终学成的仍是 `3x + 5`。

## 所以要在层间插入非线性

每层改成 `a = σ(wx + b)`，其中 σ 是**非线性**的激活函数。这样多层才能拼出弯曲的函数。

![[procreate/线性与非线性分界.png]]

**读图**：左边两类点用一条直线就能分开，单个神经元就够了；右边三类点交错分布，只有弯曲的边界才分得开，这正是需要非线性的场景。

![[procreate/线性片段拼成非线性.png]]

**读图**：f、g、i 三段每一段都是直线，拼在一起却是一条折线，整体是非线性的。神经网络也是这样：每个神经元内部是线性的，激活函数在它们之间制造「转折」，层数和神经元越多，转折点越多，能逼近的形状就越复杂。

## 框架怎样组织多层

神经网络要管理两件事：单层的参数和计算，以及层与层的组合。PyTorch 的 `nn.Module` 把这两件事用同一个类表示：一个 Module 既可以是单层，也可以是许多层的堆叠。
