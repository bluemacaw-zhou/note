# 神经元与偏置

> 总览 [[day01_00_总览|day01]] · ← [[day01_03_标量向量矩阵张量|张量]] · 下一块 → [[day01_05_多层感知机与激活函数的必要性|多层与非线性]]

**为什么需要**：需要一个**带参数的函数**把输入变成答案。所谓「学习」，就是调整这些参数。

## 神经元：加权求和再加偏置

```text
z = w₁x₁ + w₂x₂ + w₃x₃ + b = wᵀx + b
```

- **w**：每个输入的重要程度；
- **b**：整体的偏移量。

![[procreate/生物神经元与数学神经元.png]]

**读图**：左边是生物神经元，树突接收信号，轴突把信号传出去；右边是它的数学抽象，3 个输入各乘一个权重，汇总到 z。树突对应输入 x，突触的强弱对应权重 w。

## 例子：图片分类 `f(x, W) = Wx + b`

```text
x: 3072×1   一张拉平的图片
W: 10×3072  每一行是一个类别的权重
b: 10×1
f: 10×1     10 个类别各一个得分
```

课件提出的三个问题：

| 问题 | 答案 |
|---|---|
| 学习指什么？ | 找到合适的 W、b |
| 哪些已知，哪些未知？ | 图片 x 和标签已知；W、b 未知 |
| 参数量是多少？ | `10 × 3072 + 10 = 30730` |

![[procreate/图片分类Wx加b.png]]

**读图**：W 的每一行（猫 w1、狗 w2……）都和同一个 3072 维的 x 做点积，得到这个类别的得分。所以「10 个类别」等于「10 个神经元」，最后加上 10×1 的 b，就是 10 个得分。

## 偏置 b：让分界线可以不过原点

- 没有 b 时，分界线 `w₁x₁ + w₂x₂ = 0` 必然经过原点，偏离原点分布的数据就分不开。
- 加上 b，线可以平移。
- 输入是 3 维时，分界线变成分界平面，道理相同。

![[procreate/偏置让分界线离开原点.png]]

**读图**：左图那条穿过原点 O 的灰色虚线是 `x₁w₁ + x₂w₂ = 0`，没有 b 时只能绕原点转动，没法把红叉和绿点分开；红色虚线加了 b，被平移出去，与两轴的交点是 `−b/w₁`、`−b/w₂`，正好切在两类之间。右图是 3 个输入的情况，分界变成一个平面，道理相同。
