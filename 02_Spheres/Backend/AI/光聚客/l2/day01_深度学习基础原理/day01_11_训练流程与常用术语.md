## 训练循环

```text
输入 + 参数 → 计算 → 预测 → 与标签比较得到损失 ─ 达标 → 测试 → 上线
   ↑                                        │
   └──── 梯度下降 ← 反向传播 ←── 不达标 ─────┘
```

![[procreate/模型训练迭代过程.png]]

**读图**：中间的红色菱形「损失值达标」是循环的出口。没达标，就走下面那条路：反向传播调整权重，再经梯度下降更新参数，然后回到起点；达标了，才往右进入测试和应用。

## 容易混的三对术语

| 对比 | 区分 |
|---|---|
| 参数 vs 超参数 | 参数（W、b）靠训练学出来；超参数（学习率、batch size、层数、每层神经元数）由人在训练前设定 |
| 训练集 vs 测试集 | 训练集用来更新参数；测试集评估模型在**没见过的数据**上的效果。中间还有验证集，用于调参和判断何时停止，见 [[03_Collisions/2026-10-27_BERT训练追问_从过拟合判断到参数更新\|BERT 训练追问]] ① |
| epoch vs batch | 完整遍历一遍训练集算一个 epoch；每个 mini-batch 更新一次参数 |

**例子**：1000 个样本，batch size = 50，那么 1 个 epoch 要更新 20 次参数。

## 工程上的五个阶段

数据处理 → 特征工程 → 建立模型 → 评估迭代 → 上线应用，之后持续优化。
