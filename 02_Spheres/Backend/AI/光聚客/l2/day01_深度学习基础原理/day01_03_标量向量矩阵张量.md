# 标量、向量、矩阵、张量

> 总览 [[day01_00_总览|day01]] · ← [[day01_02_样本特征标签与任务类型|样本与特征]] · 下一块 → [[day01_04_神经元与偏置|神经元]]

**为什么需要**：特征要变成数字，还需要一个统一的容器，才能成批计算。

## 一个概念的四个特例

| | 阶数 | 形状 | 例子 |
|---|---|---|---|
| 标量 | 0 | `()` | 一个房价 |
| 向量 | 1 | `(n,)` | 一套房的特征 `[面积, 房龄]` |
| 矩阵 | 2 | `(m, n)` | m 套房 × n 个特征；28×28 灰度图 |
| 张量 | 任意 | `(…)` | RGB 图（高×宽×3）；视频（时间×高×宽×3） |

**区别只在阶数**：阶数等于定位一个数需要几个下标。标量、向量、矩阵都是张量的特例。

![[procreate/标量向量矩阵张量.png]]

**读图**：从左到右是单个数 → 一列 → 方格 → 叠起来的方格，每多一个排列方向，就多一阶。三维张量 `5×5×3` 就是 3 张 5×5 的矩阵叠在一起，正好对应 RGB 图片的 3 个颜色通道。

**PyTorch 里统一叫 `Tensor`**，常用属性有：

- `shape`：形状；
- `dim`：阶数；
- `dtype`：数据类型；
- `device`：在 CPU 还是 GPU 上。
