**为什么需要**：day01 分别讲了损失、梯度下降、反向传播。课堂笔记用一页把它们串成了一句话：**训练就是找 loss 最低点对应的 W**。

![[procreate/前向计算与反向传播.png]]

**读图**：左图横轴是参数 W，纵轴是 loss。在 W1 处，loss 是 loss1（蓝线）；曲线最低点对应的 W′（绿线）就是要找的参数。右边的脑图是五个要点。

## 只记 day01 没有的三点

| 要点 | 说明 |
|---|---|
| 两个阶段的别名 | 前向计算 = **模型推理**；反向传播 = **模型训练** |
| 多层 = 复合函数嵌套 | `h1 = h·w1 + b1 = (x·w + b)·w1 + b1`。反向求导就是给复合函数求导，所以要用链式法则 |
| Adam | SGD 用固定学习率；Adam 会**自动调整每个参数的步长**，见 [[day02_08_训练调优的五个讨论\|08]] |

> **修正**：课堂笔记写「loss 不能为 0，只能无限逼近于 0」，这句话不够严谨。
> - 交叉熵确实到不了 0，因为概率只能接近 1。
> - MSE 可以等于 0：数据完全落在一条直线上时，线性回归能拟合到 loss = 0。[[day02_06_从手写到框架的六步演进|06]] 的 `y = 2x + 1` 实测训练到 w = 2.0、b = 1.0。
>
> 实际训练中 loss 几乎不会等于 0，真正的原因是**数据有噪声**，而且**loss 过低往往意味着过拟合**。
