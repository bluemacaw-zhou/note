# 链式法则的矩阵形式与梯度消失

> 总览 [[day02_00_总览|day02]] · ← [[day02_02_前向计算与反向传播的目标|训练目标]] · 下一块 → [[day02_04_两层网络的手写实现|手写两层网络]]

**为什么需要**：day01_10 的链式法则是在标量 x、y、z 上算的，真实网络里流动的却是矩阵。

## 从标量到张量

```text
标量：z = f(y)，y = g(x)      →  dz/dx = dz/dy · dy/dx
张量：Y = g(X)，z = f(Y)      →  ∂z/∂xᵢ = Σⱼ (∂z/∂yⱼ) · (∂yⱼ/∂xᵢ)
```

**区别只在求和**：xᵢ 会影响 Y 的**每一个**元素，所以要把每条路径的贡献加起来。

## 一个 Matmul 节点的前向和反向

课件里的图可以写成：

```text
前向：X, W ──Matmul──→ Y ──→ ... ──→ Loss
反向：grad X, grad W ←──grad Matmul── grad Y ←── ... ←── grad Loss
```

每个前向算子都配一个反向算子。反向算子拿到下游传来的 `grad Y`，算出 `grad X`（继续往前传）和 `grad W`（用来更新参数）。

**参数矩阵和单个参数的关系**：代码里写的是整个矩阵，`dW = X·dZᵀ` 一次算完；但求偏导时，本质是**对矩阵里的每一个元素分别求导**，再把结果排成和 W 同形状的矩阵。

## 两个工程后果

| 现象 | 原因 | 后果 |
|---|---|---|
| **梯度消失**（课件称「参数消失」） | 前面层的梯度 = 后面各层的导数**连乘**。每项都小于 1 时，层数一多，乘积趋近 0 | 靠前的层几乎得不到更新 |
| **显存占用** | 反向计算要用前向的中间值（Z、A），所以前向时要**把它们都存下来** | 层越深、batch 越大，越占内存 |

和 day01_06 对照：Sigmoid 的导数最大只有 0.25，所以它是连乘变小最典型的来源。
