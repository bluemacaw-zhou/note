# 训练调优的五个讨论

**为什么需要**：模型能跑之后，问题就变成「为什么跑不好」。课件用五个讨论题来回答。

## 讨论 1：学习率对收敛的影响

day01_09 已经讲过学习率太大或太小的两种失败。课件这里补了两张实验图：

- 学习率合适：点沿着 `f(x)` 的一侧逐步滑到底部；
- 学习率过大：点在最低点两侧**来回跳**，范围在 ±50 之间，迟迟落不到底。

## 讨论 2：梯度下降为什么一定能让函数变小？

在 x 附近对 f 做一阶泰勒展开，令步长 `ε = −η·f′(x)`：

```text
f(x − η·f′(x)) = f(x) − η·f′(x)² + O(η²·f′(x)²)
```

- 只要 `f′(x) ≠ 0`，`η·f′(x)²` 就**严格大于 0**；
- η 取得足够小，高阶项 O(…) 可以忽略。

所以 `f(x − η·f′(x)) < f(x)`，每走一步函数值都会变小。**这同时说明了 η 为什么不能太大**：η 太大时，高阶项就不能忽略了。直观图见 [[2026-10-29_损失与负梯度|损失与负梯度]]。

## 讨论 3：五种优化器

```python
optim.SGD / optim.Adam / optim.RMSprop / optim.Adagrad / optim.Adadelta
```

用法完全一样，都是 `(model.parameters(), lr=…)`，切换只需改一行。

课堂笔记里的 `demo-overview.gif` 来自开源项目 gradient_descent_viz：在同一个曲面上同时放五个小球，左边的坑是**全局极小**，右边的坑是**局部极小**。

| 颜色 | 算法 | 核心想法 |
|---|---|---|
| 青 | 梯度下降 | 只看当前梯度 |
| 洋红 | Momentum | 累积之前的速度，像带惯性的球，能冲过小坑 |
| 白 | AdaGrad | 每个参数按**历史梯度平方和**缩小步长 |
| 绿 | RMSProp | 同 AdaGrad，但只看近期，步长不会一直缩小 |
| 蓝 | Adam | Momentum + RMSProp |

动画想说明：起点和算法不同，最后可能落进不同的坑。

## 讨论 4：为什么效果一直停滞不前？

课件的四张图分别对应三种「梯度接近 0，但没到最优」的地方：

| 图 | 卡住的位置 |
|---|---|
| `f(x) = x²` | 正常收敛到最小值（对照组） |
| 波浪形曲线 | **局部极小**：小坑底部梯度为 0，走不出去 |
| 起伏更大的曲线 | 步子跳过了好的坑，停在了差的坑 |
| 三维曲面 | **鞍点 / 平坦区**：一个方向是谷底，另一个方向是山顶 |

常用对策：Momentum / Adam、调整学习率、换一个初始化。

## 讨论 5：神经元越多、网络越深，效果越好吗？

课件只提了问题，没给答案。补充（非课件内容）：**不一定**。

- 参数多了容易**过拟合**（见 day01_11 的验证集）；
- 层数深了，会出现 [[day02_03_链式法则的矩阵形式与梯度消失|03]] 的梯度消失；
- 计算和显存的开销按 [[day02_07_参数量的通用公式|07]] 的公式增长。
