**为什么需要**：day01 只有公式。真正把它写成代码，才会碰到形状、缓存、激活函数求导这些细节。

## 四个函数，各管一件事

课件的两层网络：隐藏层用 tanh，输出层用 sigmoid，做二分类。

| 函数 | 职责 | 关键代码 |
|---|---|---|
| `initialize_parameters(n_x, n_h, n_y)` | 建参数 | `W1 = randn(n_h, n_x) * 0.01`，`b1 = zeros(n_h, 1)` |
| `forward_propagation(X, params)` | 前向，并**缓存中间值** | `Z1 = W1·X + b1`，`A1 = tanh(Z1)`，`Z2 = W2·A1 + b2`，`A2 = σ(Z2)`；返回 `cache = {Z1, A1, Z2, A2}` |
| `backward_propagation(params, cache, X, Y)` | 反向 | 见下 |
| `update_parameters(params, grads, lr=1.2)` | 更新 | `W1 = W1 − lr·dW1`，其余同理 |

```text
dZ2 = A2 − Y
dW2 = (1/m)·dZ2·A1ᵀ          db2 = (1/m)·Σ dZ2
dZ1 = W2ᵀ·dZ2 ⊙ (1 − A1²)    ← (1 − A1²) 是 tanh 的导数
dW1 = (1/m)·dZ1·Xᵀ           db1 = (1/m)·Σ dZ1
```

**和 day01 的区别**：day01_10 只推到单层（`dZ = A − Y`）。多了一层之后，新出现的是 `dZ1` 这一行：梯度先乘 `W2ᵀ` 传回隐藏层，再乘隐藏层激活函数的导数。

**为什么要 `cache`**：`dZ1` 要用 A1，`dW1` 要用 X。前向时不存下来，反向就得重算一遍。这就是 [[day02_03_链式法则的矩阵形式与梯度消失|03]] 说的显存代价。

**为什么初始化要乘 0.01**：权重小，Z 就落在 tanh 中间斜率大的区域，梯度不会一开始就消失。

> **勘误**：课件的文字说「W 的维度是（上一层神经元个数，下一层神经元个数）」，但它自己的代码写的是 `W1: (n_h, n_x)`，也就是**（下一层，上一层）**。以代码为准，否则 `W·X` 的形状对不上。

## 三种形状约定（容易混）

| | 课件两层网络 | demo test01 / test02 | PyTorch `nn.Linear` |
|---|---|---|---|
| X | `(特征数, 样本数)`，每列一个样本 | `(样本数, 特征数)`，每行一个样本 | `(样本数, 特征数)` |
| W | `(下一层, 上一层)` | `(上一层, 下一层)` | `weight: (输出, 输入)` |
| 前向 | `Z = W·X + b` | `h = x·w1` | `y = x·Wᵀ + b` |

实测：`nn.Linear(1000, 100).weight.shape == (100, 1000)`。PyTorch 的**存法**与课件相同，**算法**与 test01 相同，因为它在内部做了一次转置。
