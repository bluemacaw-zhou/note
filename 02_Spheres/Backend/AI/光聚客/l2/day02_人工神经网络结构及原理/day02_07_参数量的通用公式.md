# 参数量的通用公式

> 总览 [[day02_00_总览|day02]] · ← [[day02_06_从手写到框架的六步演进|六步演进]] · 下一块 → [[day02_08_训练调优的五个讨论|调优]]

**为什么需要**：参数量决定了模型的存储和计算开销，类似传统算法里的空间复杂度。day01_05 只算过一个具体例子（44），这里给出通用公式。

## 公式

输入 d 维，N 个隐藏层的宽度依次是 h₁…h_N，输出 c 维：

```text
参数量 = h₁(d + 1) + Σᵢ₌₁ᴺ⁻¹ hᵢ₊₁(hᵢ + 1) + c(h_N + 1)
```

**怎么记**：每一层的参数量都是 `输出个数 × (输入个数 + 1)`，其中的 **+1 是偏置**。公式只是把每一层的这个数加起来。

## 例子（实测与公式一致）

| 网络 | 计算 | 参数量 |
|---|---|---|
| 课件图：3 → 4 → 4 → 4 → 1 | `4×4 + 4×5 + 4×5 + 1×5` | **61** |
| demo：1000 → 100 → 10 | `100×1001 + 10×101` | **101,110** |
| 课件 MLP：784 → 128 → 10 | `128×785 + 10×129` | **101,770** |

后两个网络的规模差不多，但都比第一个大三个数量级。参数主要集中在**第一层**，因为输入维度最大。

PyTorch 里一行就能核对：`sum(p.numel() for p in model.parameters())`。
