# mongdb的docker-compose说明

## 查看 MongoDB 日志
docker-compose logs -f mongodb

## 查看 Mongo Express 日志
docker-compose logs mongo-express

## MongoDB连接信息

Host: localhost
Port: 27017
Username: admin
Password: admin
连接字符串: mongodb://admin:admin@localhost:27017/
