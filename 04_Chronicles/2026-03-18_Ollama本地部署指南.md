# Ollama 本地部署指南

## 是什么

Ollama 是本地运行大语言模型的平台，类比关系：

```
Docker : 容器镜像 = Ollama : 大语言模型
```

它本身不是模型，而是负责下载、管理和运行各种开源模型，并对外暴露统一的 HTTP 接口。

---

## 为什么部署在宿主机而不是 Docker

Mac Mini 是 Apple Silicon（M 系列），Metal GPU 加速只在宿主机上可用，容器内只能跑 CPU 推理，速度差距显著。和 whisper.cpp 同样的原因：**GPU 密集型任务统一部署在宿主机**。

---

## 安装

```bash
brew install ollama
```

---

## 启停管理

```bash
# 手动启动（按需使用，用完 Ctrl+C 停止）
ollama serve

# 开机自启动（同时完成 start + enable）
brew services start ollama

# 关闭自启动
brew services stop ollama
```

> `brew services start` 等价于 `systemctl enable --now`，一条命令同时启动并注册开机自启。

---

## 模型管理

```bash
# 下载模型
ollama pull qwen2.5:32b
ollama pull qwen2.5vl:32b

# 查看已下载的模型
ollama list

# 删除模型
ollama rm qwen2.5:32b

# 临时运行（交互式测试）
ollama run qwen2.5:32b
```

**模型存储位置**：`~/.ollama/models`，与 `~/nas/` 完全独立，重装系统或重建容器不影响已下载的模型。

**内存管理**：模型加载到内存后，空闲超过 5 分钟自动卸载，不长期占用内存。32GB 内存可运行 32b 级别模型。

---

## 推荐模型（32GB 内存）

| 模型 | 用途 | 大小 |
|------|------|------|
| `qwen2.5:32b` | 文本翻译、文字处理 | ~20GB |
| `qwen2.5vl:32b` | 图片理解、图转代码 | ~20GB |

两个模型不能同时加载，按需切换。

## 验证服务状态

```bash
# 确认服务在运行
curl localhost:11434
# 返回：Ollama is running

# 查看当前加载的模型及内存占用
curl localhost:11434/api/ps
```

---

## API 接口

Ollama 兼容 OpenAI 格式，所有需要调用 AI 的脚本统一指向 `localhost:11434`：

```bash
# 文本生成（脚本调用方式）
curl localhost:11434/api/generate \
  -d '{"model": "qwen2.5:32b", "prompt": "你好", "stream": false}'
```

当前接入的场景：
- PDF 翻译（`~/pdf2epub/translator.py`）
- SRT 字幕翻译（待开发）
- 沉浸式翻译浏览器插件（网页翻译，待配置）
