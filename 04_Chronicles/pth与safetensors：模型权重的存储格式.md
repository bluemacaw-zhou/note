# pth 与 safetensors：模型权重的存储格式

**保存模型权重时，`.pth` 和 `.safetensors` 主要存的都是训练得到的参数数值。格式不同，不代表模型能力不同。**

权重文件可以简单理解为一个字典：参数名称 → 张量。张量包含形状、数据类型和具体数值，例如全连接层的权重矩阵 `weight` 和偏置 `bias`。

- `.pth` 是 PyTorch 常用的文件后缀，通过 `torch.save` 保存；除了权重，也能保存优化器状态等训练信息。
- `.safetensors` 是专门存储张量的格式，在安全性和读取方式上有不同设计。

同一组权重以相同精度保存成这两种格式，加载后的预测效果一致。两者共存主要是用途范围和历史兼容问题，不必继续纠结格式。

当前 BERT 项目中，预训练 BERT 的参数保存在 `model.safetensors`；训练生成的 `.pth` 只保存新分类层的 `weight` 和 `bias`。两份文件大小差很多，主要因为保存的参数范围不同。

实际使用模型，还需要模型结构代码、配置和分词器等。**权重文件主要负责存数值，并不等于完整的模型运行环境。**
