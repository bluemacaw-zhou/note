# pdf2epub 工具指南

将 PDF 转换为 EPUB 电子书，上传微信读书朗读。支持双语拆分和英文翻译。

**项目目录**：`~/pdf2epub/`

---

## 组件架构

```
main.py（统一入口）
  │
  ├── pdf_parser.py    提取文本块，检测段落语言
  │         ↓
  ├── epub_builder.py  接收文本块，调用 Pandoc 生成 EPUB
  │
  ├── translator.py    接收英文文本块，调 Ollama 翻译，返回中文文本块
  │         ↓
  │    localhost:11434（Ollama，宿主机）
  │
  └── upload.py（独立入口）
            ↓
       Playwright（Firefox）驱动浏览器
            ↓
       weread.qq.com 扫码登录 + 上传
```

**各模块职责**：

| 文件 | 职责 | 依赖 |
|------|------|------|
| `pdf_parser.py` | 提取 PDF 文本块，按 CJK 字符占比判断语言 | pymupdf |
| `epub_builder.py` | 文本块 → Markdown → EPUB3 | pandoc |
| `translator.py` | 调 Ollama API 翻译，支持专业领域 prompt | requests, Ollama |
| `main.py` | 终端交互式入口，自动检测文档类型，引导操作 | 以上所有 |
| `upload.py` | Firefox 无头浏览器自动化，扫码登录微信读书，上传文件 | playwright |

## 安装

**前置依赖**：

```bash
# Pandoc（EPUB 生成）
brew install pandoc

# uv（Python 环境管理）
brew install uv
```

**项目初始化**：

```bash
cd ~/pdf2epub
uv add pymupdf pdfplumber langdetect requests playwright
uv run playwright install firefox
```

**Ollama**（翻译功能依赖，见 [[2026-03-18_Ollama本地部署指南]]）：

```bash
brew install ollama
ollama pull qwen2.5:32b
```

## 使用方法

### 主入口（推荐）

```bash
cd ~/pdf2epub
uv run python main.py <pdf文件路径>
```

**交互逻辑**：

```
解析 PDF，统计中英文段落比例
  │
  ├── 双语文档（中英各约 50%）
  │     → 是否拆分为独立中/英文 EPUB？
  │         是 → 生成中文 EPUB [可选：同时生成英文 EPUB]
  │
  ├── 中文为主（>65% 中文）
  │     → 是否转换为 EPUB？
  │
  └── 英文为主（>65% 英文）
        → 是否翻译为中文？
            是 → 选择专业领域 / 模型 → 翻译
        → 是否生成 EPUB？
```

**示例**：

```bash
# 双语金融报告 → 只取中文部分
uv run python main.py 霍华德·马克斯备忘录.pdf

# 英文技术论文 → 翻译为中文
uv run python main.py paper.pdf
# 交互中选择：翻译 → 领域选 tech → 回车使用默认模型
```

---

### 上传微信读书

```bash
uv run python upload.py <epub文件路径>
```

**流程**：
1. Firefox 无头浏览器打开 `weread.qq.com`
2. 自动点击登录，截取二维码弹窗
3. 解码二维码图片，**在终端渲染为可扫描的字符图案**
4. 用手机微信扫码（120 秒内完成）
5. 检测登录成功后跳转上传页，自动提交文件

> **注意**：登录状态不持久，每次运行都需要扫码。Cookie 持久化待后续实现。

- `debug_upload.png` — 登录后上传页截图

## 翻译配置

`translator.py` 支持 4 个专业领域，通过不同的 system prompt 提升翻译质量：

| 领域 | 适用场景 |
|------|---------|
| `general` | 通用文章 |
| `tech` | 技术文档、软件工程、计算机科学 |
| `finance` | 投资、经济、金融报告 |
| `medical` | 医疗、生命科学 |

默认模型：`qwen2.5:32b`（需 Ollama 在运行中）
