# 课程音频自动笔记实践记录

> 理论与架构：[[课程音频自动笔记]] · 工作流总览：[[2026-03-10_碎片化学习工作流方案碰撞]]

## 一、环境

- 宿主机：Mac Mini M4，macOS
- 目标目录：`~/whisper/`

**流水线：**
```
课程播放 → BlackHole 捕获音轨 → ffmpeg 录制 → whisper.cpp 转录 → .srt 字幕文件
```

**层级决策：**

| 组件 | 运行层 | 原因 |
|------|--------|------|
| BlackHole | 宿主机 | macOS 内核级虚拟音频驱动，挂接 CoreAudio，容器层无法访问 |
| ffmpeg 录制 | 宿主机 | 需要访问 BlackHole 音频设备 |
| whisper.cpp | 宿主机 | M4 Metal GPU 加速，容器层（Linux VM）跑不了 Metal，慢 5-10 倍 |

## 二、安装过程

### 2.1 安装 BlackHole

```bash
brew install blackhole-2ch
```

安装后需要**重启**，否则 BlackHole 不会出现在音频设备列表中。

### 2.2 配置多输出设备

1. 打开 **音频 MIDI 设置**（Audio MIDI Setup.app）
2. 左下角 **+** → 新建「多输出设备」
3. 勾选：扬声器/耳机 + BlackHole 2ch
4. 勾选 BlackHole 一行的「**漂移校正**」（主设备扬声器不勾）
5. 系统设置 → 声音 → 输出 → 选择该多输出设备

> **无声录制（推荐）**：若不需要听声音，直接在系统设置 → 声音 → 输出中选 **BlackHole 2ch**（跳过多输出设备），音频全部进入 BlackHole，无多设备时钟同步开销，录制质量更好，无丢音风险。录制完成后再切回扬声器/耳机。

### 2.3 安装 ffmpeg

```bash
brew install ffmpeg
```

查找 BlackHole 的设备索引：

```bash
ffmpeg -f avfoundation -list_devices true -i "" 2>&1
# [0] BlackHole 2ch  ← 音频设备索引 0
```

### 2.4 编译 whisper.cpp（启用 Metal）

```bash
git clone https://github.com/ggerganov/whisper.cpp ~/whisper.cpp
cd ~/whisper.cpp
cmake -B build -DGGML_METAL=ON
cmake --build build -j8
```

编译成功标志：日志中出现 `Metal framework found` 和 `Including METAL backend`。

### 2.5 下载模型

从 HuggingFace 手动下载（需代理）：

```
https://huggingface.co/ggerganov/whisper.cpp/resolve/main/ggml-medium.bin
```

放到 `~/whisper/models/ggml-medium.bin`。

> small 模型（466MB）专业词汇准确率不足，实测后升级为 medium（1.5GB）。

### 2.6 整理目录，清理源码

编译完成后，将产物迁移到 `~/whisper/bin/`，删除源码：

```bash
mkdir -p ~/whisper/bin
cp ~/whisper.cpp/build/bin/whisper-cli ~/whisper/bin/
find ~/whisper.cpp/build -name "*.dylib" -exec cp {} ~/whisper/bin/ \;
install_name_tool -add_rpath ~/whisper/bin ~/whisper/bin/whisper-cli
rm -rf ~/whisper.cpp
```

最终目录结构：

```
~/whisper/
├── bin/            whisper-cli + dylib
├── models/         ggml-medium.bin
├── audio/          录制文件 + 转录结果
└── record_and_transcribe.sh
```

## 三、录制与转录脚本

`~/whisper/record_and_transcribe.sh`：

```bash
#!/bin/bash
NAME=${1:-recording}
AUDIO=~/whisper/audio/${NAME}.wav
SRT=~/whisper/audio/${NAME}

echo "开始录制，按 q 停止..."
ffmpeg -f avfoundation -i ":0" -c:a pcm_s16le "$AUDIO"

echo "转录中..."
~/whisper/bin/whisper-cli -m ~/whisper/models/ggml-medium.bin -l zh -f "$AUDIO" -osrt -of "$SRT" 2>/dev/null

echo "完成：${SRT}.srt"
```

用法：

```bash
~/whisper/record_and_transcribe.sh NO.297
# 按 q 停止录制，自动生成 ~/whisper/audio/NO.297.srt
```

## 四、遇到的问题

| 问题 | 原因 | 解决 |
|------|------|------|
| `Error opening input file BlackHole 2ch` | avfoundation 需要索引号，不能用设备名 | 改用 `:0` |
| 录制有丢音 | 多输出设备时钟同步问题 | 勾选 BlackHole 的漂移校正；或直接选 BlackHole 作为系统输出 |
| `failed to read audio data as wav` | whisper-cli 只支持 WAV，不支持 M4A | 录制直接用 `-c:a pcm_s16le` 输出 WAV |
| `bad interpreter: /bin/bash^M` | 脚本含 Windows 换行符 | `sed -i '' 's/\r//' script.sh` |
| HuggingFace 无法下载模型 | 网络限制 | 手动通过代理下载 |

## 五、验证结果

- 测试音频：金融类课程，约 4 分钟

- 转录耗时：约 30 秒（M4 Metal GPU）
- 转录质量：专业词汇准确率良好，语义基本通顺

## 六、AI 校对与 Obsidian 笔记（2026-03-24 完成）

### 流水线

```
.srt 字幕文件
  → Gemini（save-note skill）整理转录内容
  → 结构化 Markdown 笔记
  → 写入 ~/workspace/note/（Obsidian vault）
```

### 执行命令

```bash
# 将字幕整理为结构化笔记，写入 Obsidian
cat "/path/to/course.srt" | gemini -p "将以下课程字幕整理为结构化Markdown笔记：提取核心要点，生成清晰标题，输出完整Markdown。" \
  > ~/workspace/note/01_Curiosities/<主题>/<课程名>.md
```

### 触发方式

通过 Slack 告知 agent：「帮我把这节课的字幕整理成笔记」→ agent 调用 `save-note` skill 执行。
不是全自动（需手动触发），但流程固化，单条命令完成。

### 离线字幕生成（私域课程补充）

私域课程（小鹅通等）视频已下载到本地，可直接离线生成字幕，无需实时 BlackHole 录制：

```bash
# 从 mp4 文件直接转录（更稳定，无需系统音频配置）
ffmpeg -i course.mp4 -ar 16000 -ac 1 -c:a pcm_s16le /tmp/audio.wav -y
~/whisper/bin/whisper-cli -m ~/whisper/models/ggml-medium.bin \
  -l auto -osrt -of course \
  --max-len 80 --split-on-word /tmp/audio.wav
```

实时 BlackHole 录制适合无法提前下载的直播/在线课程，已下载视频用离线方式更可靠。
