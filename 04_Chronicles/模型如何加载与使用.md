# 模型如何加载与使用

**模型可以直观理解成一层层神经元的计算。加载时搭好结构、填入权重；使用时做前向计算。**

- **模型代码**：定义每层怎么计算、层与层怎么连接。
- **配置文件**：指定层数、每层维度等结构参数。
- **权重文件**：保存各层训练好的参数数值，加载到对应层。
- **词表和分词器**：把文字转换成模型能接收的 token ID。

注意：**层数等结构信息从配置读取，训练好的权重从权重文件读取。**

```text
模型代码 + 配置 → 搭好网络 → 加载各层权重

文字 → 分词器 → token ID → 模型做一次前向计算 → 输出结果
```

对于当前 BERT 模型，加载通常只做一次，后续每次调用复用权重，进行一次前向计算。
