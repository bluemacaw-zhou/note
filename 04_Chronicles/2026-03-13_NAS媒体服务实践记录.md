## 二、OrbStack Docker 部署

### docker-compose.yml

路径：`~/nas/docker-compose.yml`

```yaml
name: media

services:
  jellyfin:
    image: jellyfin/jellyfin:latest
    container_name: media-jellyfin
    ports:
      - "8096:8096"
    volumes:
      - ${HOME}/nas/config/jellyfin:/config
      - ${HOME}/nas/media:/media
    environment:
      - TZ=Asia/Shanghai
    restart: unless-stopped

  qbittorrent:
    image: lscr.io/linuxserver/qbittorrent:latest
    container_name: media-qbittorrent
    ports:
      - "8080:8080"
      - "6881:6881"
      - "6881:6881/udp"
    volumes:
      - ${HOME}/nas/config/qbittorrent:/config
      - ${HOME}/nas/downloads:/downloads
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=Asia/Shanghai
      - WEBUI_PORT=8080
    restart: unless-stopped

  sonarr:
    image: lscr.io/linuxserver/sonarr:latest
    container_name: media-sonarr
    ports:
      - "8989:8989"
    volumes:
      - ${HOME}/nas/config/sonarr:/config
      - ${HOME}/nas/media:/media
      - ${HOME}/nas/downloads:/downloads
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=Asia/Shanghai
    restart: unless-stopped

  radarr:
    image: lscr.io/linuxserver/radarr:latest
    container_name: media-radarr
    ports:
      - "7878:7878"
    volumes:
      - ${HOME}/nas/config/radarr:/config
      - ${HOME}/nas/media:/media
      - ${HOME}/nas/downloads:/downloads
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=Asia/Shanghai
    restart: unless-stopped

  prowlarr:
    image: lscr.io/linuxserver/prowlarr:latest
    container_name: media-prowlarr
    ports:
      - "9696:9696"
    volumes:
      - ${HOME}/nas/config/prowlarr:/config
    environment:
      - PUID=1000
      - PGID=1000
      - TZ=Asia/Shanghai
    restart: unless-stopped
```

### 命名空间

`name: media` 使所有容器前缀为 `media-*`，共享内部网络 `media_default`。容器间通信使用服务名（如 `http://qbittorrent:8080`），不能用 `localhost`。

## 三、资源文件结构

```
~/nas/
├── docker-compose.yml
│
├── config/                    ← 各服务配置，挂载进容器 /config
│   ├── jellyfin/
│   │   └── config/
│   │       └── encoding.xml   ← ffmpeg 路径配置（手动修改过）
│   ├── qbittorrent/
│   ├── sonarr/
│   │   └── config.xml         ← 含 ApiKey
│   ├── radarr/
│   │   └── config.xml         ← 含 ApiKey
│   └── prowlarr/
│       └── config.xml         ← 含 ApiKey
│
├── media/                     ← 整理后的最终媒体文件
│   ├── movies/                ← Radarr 整理落盘
│   │   └── Zootopia 2 (2025)/
│   └── tv/                    ← Sonarr 整理落盘
│       └── A Knight of the Seven Kingdoms/
│           └── Season 1/
│
└── downloads/                 ← qBittorrent 下载目录
    ├── completed/
    │   ├── sonarr/            ← Sonarr 发起的任务
    │   └── radarr/            ← Radarr 发起的任务
    └── incomplete/
```

**hardlink 设计**：`media` 和 `downloads` 在同一宿主机卷，Sonarr/Radarr 整理时执行 hardlink 而非复制，零时间、零额外空间。

### 5.4 Prowlarr 注册 Sonarr/Radarr（同步机制）

Prowlarr 通过 `/api/v1/applications` 注册 Sonarr 和 Radarr，添加新 indexer 后自动同步给两者，无需手动在 Sonarr/Radarr 里填 Torznab URL。

```bash
# Prowlarr 注册 Sonarr 的 API 调用格式
POST http://localhost:9696/api/v1/applications
{
  "name": "Sonarr",
  "syncLevel": "fullSync",
  "fields": [
    {"name": "prowlarrUrl", "value": "http://prowlarr:9696"},
    {"name": "baseUrl", "value": "http://sonarr:8989"},
    {"name": "apiKey", "value": "<Sonarr ApiKey>"}
  ]
}
```

## 六、关键配置说明

### 6.1 Jellyfin ffmpeg 路径（手动修复）

`~/nas/config/jellyfin/config/encoding.xml` 需要手动添加：

```xml
<EncoderAppPath>/usr/lib/jellyfin-ffmpeg/ffmpeg</EncoderAppPath>
```

首次启动该字段为空，Jellyfin 找不到 ffmpeg 无法转码。iPhone 播放 MKV/HEVC 必须转码，不修复则黑屏。

### 6.2 qBittorrent 固定密码

linuxserver 镜像每次重启生成随机临时密码，需首次启动后立即固定：

```bash
# 1. 用临时密码登录，拿 session cookie（临时密码在容器日志里）
curl -c /tmp/qb.cookie 'http://localhost:8080/api/v2/auth/login' \
  --data 'username=admin&password=<临时密码>'

# 2. 修改为固定凭据
curl -b /tmp/qb.cookie 'http://localhost:8080/api/v2/app/setPreferences' \
  --data 'json={"web_ui_username":"michael","web_ui_password":"michael"}'
```

### 6.3 Sonarr/Radarr Root Folder

必须配置，否则添加内容时报 400：

```bash
# Sonarr
curl -X POST http://localhost:8989/api/v3/rootfolder \
  -H "X-Api-Key: c5d25520a69c428bbe5209908bbafcaf" \
  -H "Content-Type: application/json" \
  -d '{"path":"/media/tv"}'

# Radarr
curl -X POST http://localhost:7878/api/v3/rootfolder \
  -H "X-Api-Key: 8a9b154e4d10498c971ff4551a562116" \
  -H "Content-Type: application/json" \
  -d '{"path":"/media/movies"}'
```

### 6.4 Jellyfin 远程码率限制

阿里云 ECS 带宽 3Mbps，远程播放需限制码率：

```bash
# 已通过 API 设置 RemoteClientBitrateLimit = 2,000,000 bps（2Mbps）
POST http://localhost:8096/System/Configuration
```

## 七、常用运维命令

```bash
# 启动所有服务
cd ~/nas && docker compose up -d

# 查看运行状态
docker compose ps

# 实时查看某服务日志
docker compose logs -f jellyfin

# 更新所有镜像
docker compose pull && docker compose up -d

# 重建单个容器（不丢数据）
docker compose up -d --force-recreate sonarr

# 重启单个服务
docker compose restart jellyfin
```
