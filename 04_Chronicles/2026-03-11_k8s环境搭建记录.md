# k8s 环境搭建实验记录

## 1. 实验准备

### 1.1 宿主机环境
- 设备：Mac Mini (Apple Silicon, 32G RAM)
- 存储路径：`~/k8s-storage` (用于 PV/PVC 实验)

### 1.2 预期架构
- 集群名称：`lab-cluster`
- 节点：1 Master + 3 Agents
- 存储类：`local-path` 指向宿主机路径
- 调度策略：Master 节点打上 `NoSchedule` 污点，业务 Pod 只调度到 Agent

---

## 2. 操作流水线

### Step 1: 安装工具
```bash
brew install --cask orbstack
brew install k3d kubectl derailed/k9s/k9s
```

### Step 2: 建立磁盘映射桥梁
```bash
mkdir -p ~/k8s-storage
```

### Step 3: 一键启动集群 (1 Master + 3 Agents + Taint)
```bash
k3d cluster create lab-cluster \
  --servers 1 \
  --agents 3 \
  -v /Users/michael/k8s-storage:/mnt/master-data@all \
  --k3s-arg "--disable=traefik@server:0" \
  --k3s-arg "--node-taint=node-role.kubernetes.io/master=true:NoSchedule@server:0"
```
