## 插件简介

**Obsidian Web Clipper** 是官方浏览器扩展，支持快速保存网页。

**支持浏览器**：
- Chrome/Edge
- Firefox
- Safari

**核心功能**：
- 保存整个网页
- 保存选中内容
- 保存为 Markdown
- 自动提取正文

## 安装配置

### 安装扩展

**Chrome/Edge**：
```
访问：Chrome Web Store
搜索：Obsidian Web Clipper
安装：点击"添加到 Chrome"
```

**Firefox**：
```
访问：Firefox Add-ons
搜索：Obsidian Web Clipper
安装：点击"添加到 Firefox"
```

**Safari**：
```
访问：App Store
搜索：Obsidian Web Clipper
安装：下载 Safari 扩展
```

### 配置连接

**Obsidian 设置**：
```
1. 打开 Obsidian
2. 设置 → 第三方工具 → Web Clipper
3. 启用 Web Clipper
4. 设置 REST API 密钥
```

**扩展配置**：
```
1. 点击扩展图标
2. 选择本地或远程 Vault
3. 输入 API 密钥
4. 测试连接
```

## 使用方法

### 1. 保存模式

**完整页面**：
```
点击扩展 → 选择"完整页面"
→ 保存整个网页内容
```

**仅正文**：
```
点击扩展 → 选择"仅正文"
→ 自动提取主要内容
→ 去除导航和广告
```

**选中内容**：
```
网页中选中文字 → 右键 → Obsidian Clipper
→ 只保存选中部分
```

**智能剪藏**：
```
点击扩展 → 选择"智能剪藏"
→ AI 分析页面结构
→ 提取关键内容
```

### 2. 保存选项

**基本选项**：
```yaml
保存位置:
  - 收件箱/
  - 固定文件夹
  - 每次询问

文件名:
  - 网页标题
  - 自定义名称

格式:
  - Markdown
  - HTML
```

**高级选项**：
```yaml
内容:
  - 保留链接
  - 下载图片
  - 提取高亮

元数据:
  - 添加来源 URL
  - 保存日期
  - 添加标签
```

### 3. 快速操作

**快捷键**：
```
Chrome/Edge: Alt + Shift + O
Firefox: Alt + Shift + O
```

**右键菜单**：
```
选中文字 → 右键
→ "保存到 Obsidian"
→ 快速保存
```

## 高级配置

### 模板配置

**自定义模板**：
```markdown
---
title: "{{title}}"
source: "{{url}}"
saved_at: "{{date}}"
tags: [clipper, web]
---

# {{title}}

> 来源：[{{url}}]({{url}})

## 内容

{{content}}

## 笔记


---
```

### 文件夹规则

**动态文件夹**：
```yaml
规则:
  - 域名匹配: github.com
    → 保存到: 收藏/代码/
  - 域名匹配: youtube.com
    → 保存到: 收藏/视频/
  - 默认:
    → 保存到: 收件箱/
```

### 自动处理

**自动标签**：
```yaml
关键词标签:
  - "编程" → #技术
  - "设计" → #设计
  - "产品" → #产品
```

**图片处理**：
```yaml
图片:
  - 下载到: attachments/{{date}}/
  - 重命名: 自动
  - 转换格式: webp
```

## 常见问题

### Q1：无法连接到 Obsidian？

**A**：
- 确认 Obsidian 已打开
- 检查 REST API 是否启用
- 重新输入 API 密钥

### Q2：保存的格式混乱？

**A**：
- 使用"仅正文"模式
- 或手动调整格式
- 考虑使用 Readability 模式

### Q3：图片无法保存？

**A**：
- 检查网络连接
- 确认有下载图片权限
- 部分网站可能禁止图片下载
