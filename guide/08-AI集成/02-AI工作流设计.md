## 工作流模式

### 1. 收集-整理-创作 (CAC)

```
收集 (Capture)
  ↓ AI 辅助标签和分类
整理 (Organize)
  ↓ AI 生成摘要和关联
创作 (Create)
  ↓ AI 辅助写作和优化
```

### 2. PAR + AI

**P - Project (项目)**：
```
AI 协助：
- 项目规划建议
- 任务分解
- 风险识别
```

**A - Area (领域)**：
```
AI 协助：
- 领域知识梳理
- 关键概念提取
- 学习路径建议
```

**R - Resource (资源)**：
```
AI 协助：
- 资源质量评估
- 内容摘要
- 相关性分析
```

### 3. SMART 工作流

```
Search (搜索)
  ↓ AI 优化搜索关键词
Map (映射)
  ↓ AI 绘制知识图谱
Apply (应用)
  ↓ AI 辅助实践
Review (回顾)
  ↓ AI 生成回顾报告
Transform (转化)
  ↓ AI 协助知识重构
```

## 场景应用

### 场景1：学术研究

**文献阅读**：
```
1. PDF → AI 摘要核心观点
2. 提取关键概念 → AI 建立概念图谱
3. 关联已有笔记 → AI 推荐相关文献
4. 写作文献综述 → AI 辅助论证和润色
```

**AI 辅助提问**：
```
基于这篇论文的核心观点，请：
1. 总结研究方法
2. 分析创新点
3. 指出局限性
4. 建议后续研究方向
```

### 场景2：技术文档

**API 文档**：
```
1. 代码 → AI 生成注释
2. 功能说明 → AI 补充示例
3. 使用场景 → AI 生成最佳实践
```

**AI 辅助写作**：
```
请根据以下 API 设计生成文档：
- 函数说明
- 参数列表
- 返回值
- 异常处理
- 使用示例
```

### 场景3：会议记录

**实时记录**：
```
1. 会议中快速记录要点
2. AI 自动整理结构
3. AI 生成行动项
4. AI 提取决策事项
```

**AI 整理模板**：
```
请整理以下会议记录：
- 提取讨论主题
- 总结决议事项
- 列出行动项和负责人
- 标注待解决问题
```

## 提示词模板

### 学习笔记

```markdown
---
prompt: |
  你是学习助手，请根据以下内容生成学习笔记：

  ## 学习目标
  {{learning_objective}}

  ## 核心内容
  {{content}}

  请生成：
  1. 关键概念列表（5-7个）
  2. 知识点解释
  3. 个人思考问题
  4. 实践建议
---
```

### 项目规划

```markdown
---
prompt: |
  作为项目管理专家，请协助项目规划：

  ## 项目背景
  {{background}}

  ## 项目目标
  {{goals}}

  请提供：
  1. 项目阶段划分
  2. 关键里程碑
  3. 风险识别
  4. 资源需求
---
```

### 文档审阅

```markdown
---
prompt: |
  请审阅以下文档，提供改进建议：

  ## 审阅标准
  - 内容准确性
  - 逻辑清晰度
  - 表达规范性
  - 格式一致性

  ## 文档内容
  {{content}}

  请提供：
  1. 整体评价
  2. 具体问题列表
  3. 改进建议
  4. 修改优先级
---
```

## 效率提升

### 1. 快速启动

**命令快捷键**：
```yaml
# hotkeys for Copilot
Ctrl/Cmd + Alt + A: 打开 AI 对话
Ctrl/Cmd + Alt + S: AI 摘要
Ctrl/Cmd + Alt + C: AI 续写
```

### 2. 模板库

**常用提示词**：
```
Templates/
  ├── 学习笔记.md
  ├── 会议记录.md
  ├── 文档审阅.md
  ├── 代码解释.md
  └── 创意生成.md
```

## 最佳实践

> [!tip] 工作流优化
> 1. **明确目标**：清楚知道 AI 要解决什么问题
> 2. **迭代优化**：根据结果调整提示词
> 3. **人机协作**：AI 辅助，人类决策
> 4. **持续学习**：积累有效的提示词模板

> [!tip] 提示词技巧
> 1. **角色设定**：为 AI 设定专业角色
> 2. **上下文充分**：提供足够的背景信息
> 3. **输出格式**：明确期望的输出格式
> 4. **示例引导**：提供参考示例
