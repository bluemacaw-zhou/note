## 基础操作

### 文件操作

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + N` | 新建笔记 |
| `Ctrl/Cmd + O` | 打开笔记 |
| `Ctrl/Cmd + S` | 保存当前笔记 |
| `Ctrl/Cmd + P` | 快速切换 |
| `Ctrl/Cmd + Shift + F` | 在当前文件夹搜索 |

### 视图切换

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + E` | 切换编辑/预览模式 |
| `Ctrl/Cmd + Shift + E` | 编辑/预览并排 |
| `F11` | 进入阅读模式 |
| `Ctrl/Cmd + \` | 显示/隐藏侧边栏 |

## 编辑快捷键

### 文本编辑

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + B` | 粗体 |
| `Ctrl/Cmd + I` | 斜体 |
| `Ctrl/Cmd + K` | 插入链接 |
| `Ctrl/Cmd + Shift + K` | 插入引用 |
| `Ctrl/Cmd + D` | 删除选中文字 |
| `Ctrl/Cmd + Z` | 撤销 |
| `Ctrl/Cmd + Shift + Z` | 重做 |

### 列表操作

| 快捷键 | 功能 |
|--------|------|
| `Enter` | 新建列表项 |
| `Tab` | 缩进列表项 |
| `Shift + Tab` | 取消缩进 |
| `Ctrl/Cmd + Enter` | 在当前行下方插入新行 |

## 命令面板

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + P` | 打开命令面板 |

**常用命令**：
- "Create new note" - 创建新笔记
- "Open today's note" - 打开今日笔记
- "Toggle checkbox" - 切换复选框
- "Format as table" - 格式化为表格

## 自定义快捷键

**设置路径**：设置 → 快捷键

**推荐自定义**：

| 功能 | 推荐快捷键 |
|------|-----------|
| 打开每日日志 | `Ctrl/Cmd + Alt + D` |
| 创建会议记录 | `Ctrl/Cmd + Alt + M` |
| 切换编辑/预览 | `Ctrl/Cmd + E` |
| 插入代码块 | `Ctrl/Cmd + Alt + C` |
