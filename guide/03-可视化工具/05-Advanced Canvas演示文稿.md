## 插件简介

**Advanced Canvas** 是 Canvas 的增强插件。

**核心功能**：
- 单向箭头连接
- 演示模式
- 幻灯片切换
- 分组管理

## 单向箭头模式

### 创建演示文稿

**基本结构**：
```
封面页 (卡片)
  ↓ 单向箭头
目录页 (卡片)
  ↓ 单向箭头
内容页1 (卡片)
  ↓ 单向箭头
内容页2 (卡片)
  ↓ 单向箭头
结束页 (卡片)
```

### 操作步骤

**1. 创建 Canvas**：
```
1. 创建新 Canvas 文件
2. 设置画布大小（推荐 1920x1080）
```

**2. 添加卡片**：
```
1. 使用矩形或文本卡片
2. 设置卡片大小（推荐 800x600）
3. 添加内容
```

**3. 连接卡片**：
```
1. 使用 Advanced Canvas 的箭头工具
2. 从一张卡片拖拽到下一张
3. 确保箭头是单向的
```

## 演示设置

### 快捷键

| 快捷键 | 功能 |
|--------|------|
| `方向键` | 切换到下一张 |
| `Shift + 方向键` | 反向切换 |
| `F` | 全屏模式 |
| `Esc` | 退出演示 |

### 演示技巧

**进入演示模式**：
```
1. 点击第一张卡片
2. 按 `F` 进入全屏
3. 使用方向键切换
```

**跳转到特定页面**：
```
1. 点击目标卡片
2. 自动聚焦
```

## 最佳实践

> [!tip] 设计建议
> 1. **卡片统一**：使用相同的卡片大小
> 2. **颜色编码**：不同章节使用不同颜色
> 3. **清晰箭头**：使用明显的箭头样式
> 4. **预览测试**：演示前测试箭头连接

> [!tip] 内容建议
> 1. **每页一主题**：不要在一张卡片放太多内容
> 2. **使用双链**：链接到详细文档
> 3. **嵌入媒体**：使用图片和视频
> 4. **保持简洁**：重点突出

## 与普通 Canvas 的区别

| 功能 | 普通 Canvas | Advanced Canvas |
|------|-----------|-----------------|
| 箭头方向 | 任意 | 支持单向限制 |
| 演示模式 | 无 | 内置演示模式 |
| 分组 | 基础 | 增强分组 |
| 样式 | 默认 | 更多样式选项 |
