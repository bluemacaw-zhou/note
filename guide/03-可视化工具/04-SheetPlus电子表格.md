## 插件简介

**SheetPlus** 是一个强大的表格插件，提供了类似 Excel 的功能：

**核心特性**：
- Excel 风格的表格编辑
- 支持公式和函数
- 条件格式化
- 数据排序和筛选
- 图表生成

---

## 安装配置

### 安装步骤

1. **安装插件**
   - 设置 → 社区插件 → 浏览
   - 搜索 "SheetPlus"
   - 安装并启用

2. **基本配置**
   ```yaml
   SheetPlus:
     Default View: spreadsheet    # 默认视图
     Auto Save: true              # 自动保存
     Show Formula: false          # 显示公式
   ```

## 基础操作

### 创建表格

**方法1：命令面板**
```markdown
1. Ctrl/Cmd + P 打开命令面板
2. 输入 "SheetPlus: Create new table"
3. 选择插入位置
```

**方法2：Markdown 语法**
```markdown
<!-- 输入以下内容，然后点击 "Open in SheetPlus" -->
| 姓名 | 部门 | 职位 |
|------|------|------|
| 张三 | 技术部 | 工程师 |
| 李四 | 产品部 | 经理 |
```

### 编辑操作

| 操作 | 快捷键 | 说明 |
|------|--------|------|
| 编辑单元格 | `Enter` | 进入编辑模式 |
| 确认编辑 | `Tab` / `Enter` | 保存并移动 |
| 插入行 | `Ctrl/Cmd + Shift + +` | 在当前位置插入 |
| 删除行 | `Ctrl/Cmd + -` | 删除当前行 |
| 复制 | `Ctrl/Cmd + C` | 复制选中单元格 |
| 粘贴 | `Ctrl/Cmd + V` | 粘贴内容 |

## 公式与函数

### 基础公式

**算术运算**：
```excel
# 加法
=SUM(A1:A10)

# 平均值
=AVERAGE(B1:B20)

# 计数
=COUNT(C1:C30)

# 最大值
=MAX(D1:D15)

# 最小值
=MIN(E1:E15)
```

### 文本函数

```excel
# 连接文本
=CONCATENATE(A1, " ", B1)

# 文本长度
=LEN(A1)

# 左侧字符
=LEFT(A1, 5)

# 右侧字符
=RIGHT(A1, 3)
```

### 条件函数

```excel
# IF 条件
=IF(A1>100, "高", "低")

# AND 条件
=AND(A1>50, B1<100)

# OR 条件
=OR(A1="完成", B1="关闭")
```

## 高级功能

### 1. 条件格式化

```excel
# 设置规则
=IF(A1>100, "color: red", "color: green")

# 状态颜色
=IF(E2="完成", "background: #d4edda", "background: #fff3cd")
```

### 2. 数据验证

```excel
# 下拉列表
=DATAVALIDATE("进行中,已完成,未开始")

# 数值范围
=DATAVALIDATE("0-100")
```

### 3. 图表生成

```excel
# 创建图表
=CHART(TYPE:bar, DATA:A1:B10, TITLE:"项目进度")

# 饼图
=CHART(TYPE:pie, DATA:A2:B5, TITLE:"预算分布")
```

## 常见问题

### Q1：如何将 Markdown 表格转为 SheetPlus？

**A**：
1. 打开包含 Markdown 表格的笔记
2. 点击表格上方的 "Open in SheetPlus" 按钮
3. 或使用命令 `SheetPlus: Convert table`

### Q2：公式不计算怎么办？

**A**：
- 确认公式以 `=` 开头
- 检查单元格引用是否正确
- 查看控制台错误信息

### Q3：如何导出为 Excel？

**A**：
- 使用 `SheetPlus: Export to CSV` 命令
- 在 Excel 中打开 CSV 文件
- 或使用插件 `Excel Tools` 直接导出

## 最佳实践

> [!tip] 使用建议
> 1. **数据类型**：明确列的数据类型（文本、数字、日期）
> 2. **公式命名**：使用命名范围提高可读性
> 3. **数据验证**：使用数据验证防止错误输入
> 4. **备份重要数据**：定期备份关键表格数据
