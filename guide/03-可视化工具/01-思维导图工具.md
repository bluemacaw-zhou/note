## 插件对比

| 插件 | 特点 | 适用场景 |
|------|------|----------|
| Mindmap NextGen | 自动生成，易用 | 快速创建思维导图 |
| Markmap | 基于 Markdown，轻量 | 代码与可视化结合 |
| Advanced Canvas | 手动绘制，灵活 | 复杂图形设计 |

---

## Mindmap NextGen

### 安装配置
```yaml
设置 → 社区插件 → 浏览 → 搜索 "Mindmap" → 安装
```

### 使用方法
```markdown
```mindmap
# 中心主题
## 子主题1
### 次级主题
## 子主题2
```
```

---

## Markmap

### 安装配置
```yaml
# 通过 Code Mirage 插件集成
设置 → Code Mirage → 启用 Markmap
```

### 使用方法
````markdown
```markmap
# Obsidian

## 核心功能
### 双链
### 标签
### 插件

## 使用场景
### 笔记
### 知识管理
### 协作
```
````
