## Charts 插件

### 安装配置
```yaml
设置 → 社区插件 → 浏览 → 搜索 "Charts" → 安装
```

### 使用方法
````markdown
```charts
type: bar
labels: [一月, 二月, 三月]
series:
  - title: 收入
    data: [100, 120, 140]
  - title: 支出
    data: [80, 90, 95]
```
````

## Mermaid 图表

### 内置支持
```yaml
Obsidian 内置支持 Mermaid，无需额外安装
```

### 常用图表

**流程图**：
````markdown
```mermaid
graph LR
A[开始] --> B{判断}
B -->|是| C[执行]
B -->|否| D[结束]
C --> D
```
````

**时序图**：
````markdown
```mermaid
sequenceDiagram
    用户->>系统: 登录请求
    系统->>数据库: 验证
    数据库-->>系统: 返回结果
    系统-->>用户: 登录成功
```
````

**甘特图**：
````markdown
```mermaid
gantt
    title 项目进度
    dateFormat YYYY-MM-DD
    section 需求
    需求分析 :a1, 2026-03-01, 7d
    section 开发
    前端开发 :a2, after a1, 14d
    后端开发 :a3, after a1, 14d
```
````
