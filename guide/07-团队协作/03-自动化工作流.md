## Templater 自动化

### 模板系统

**安装配置**：
```yaml
设置 → 社区插件 → Templater
Template folder location: templates
Trigger Templater on new file creation: true
```

### 常用模板

**会议记录模板**：
```markdown
---
title: {{title}}
date: {{date}}
attendees: <% await tp.system.prompt("参会人员") %>
type: <% await tp.suggester(["周会", "评审", "讨论"], ["周会", "评审", "讨论"]) %>
---

# {{title}}

## 参会人员
<% attendees.split(",").forEach(p => { %>
- <% p %>
<% }) %>

## 议程


## 讨论内容


## 决议事项


## 行动项
| 任务 | 负责人 | 截止日期 |
|------|--------|----------|
|      |        |          |

## 下次会议
- 时间：
- 议题：
```

**项目文档模板**：
```markdown
---
title: {{title}}
project: <% tp.config.project_name %>
type: <% tp.config.doc_type %>
status: 草稿
assignee: <% tp.config.assignee %>
created: {{date}}
---

# {{title}}

## 概述


## 需求


## 设计


## 实现


## 测试


## 参考
```

### 动态脚本

**日期计算**：
```markdown
<%*
// 计算截止日期
const today = tp.date.now("YYYY-MM-DD");
const deadline = tp.date.now("YYYY-MM-DD", 7);
t`创建日期：${today}`;
t`截止日期：${deadline}`;
*%>
```

**文件列表**：
```markdown
<%*
// 列出本周文件
const files = tp.user.get_weekly_files();
files.forEach(file => {
  t`- [[${file.basename}]]`;
});
*%>
```

## QuickAdd 工作流

### 基础配置

**安装**：
```yaml
设置 → 社区插件 → QuickAdd
```

### 创建 Choice

**快速创建任务**：
```javascript
// QuickAdd Choice
- Name: 创建任务
- Type: Template
- Template: 任务模板.md

// Template 内容
- [ ] {{VALUE}}
```

**快速会议记录**：
```javascript
// QuickAdd Macro
1. 创建文件：`会议记录/{{date}}.md`
2. 插入模板：会议模板
3. 打开文件
4. 移动光标到第一行
```

### Macro 脚本

**自动化流程**：
```javascript
// Macro: 每日日报
const steps = [
  {
    type: "CreateNote",
    filePath: "日志/{{date:YYYY-MM-DD}}.md",
  },
  {
    type: "Template",
    template: "日报模板",
  },
  {
    type: "Open",
  },
];
```

**用户输入**：
```javascript
// 获取用户输入
const title = await quickadd.input("标题");
const tags = await quickadd.suggester(
  ["重要", "紧急", "普通"],
  ["#重要", "#紧急", "#普通"]
);
```

### 案例1：每日日报

**Templater 模板**：
```markdown
---
date: {{date:YYYY-MM-DD}}

---

# 📅 {{date:YYYY-MM-DD}} {{date:dddd}}
```

```javascript

2. 应用模板：日报模板
3. 添加到日记列表
4. 打开文件
```

## 最佳实践

> [!tip] 自动化建议
> 1. **从简开始**：先自动化最常用的操作
> 2. **逐步优化**：根据使用反馈改进流程
> 3. **保持灵活**：不要过度自动化，保留手动选项
> 4. **文档同步**：更新模板时同步更新文档

> [!tip] 模板设计
> 1. **结构清晰**：使用标题和分隔符组织内容
> 2. **填写提示**：使用占位符提示需要填写的内容
> 3. **元数据完整**：包含所有必要的 frontmatter
> 4. **易于扩展**：预留扩展空间

## 常见问题

### Q1：模板变量不生效？

**A**：
- 确认 Templater 已启用
- 检查语法是否正确
- 查看控制台错误信息

### Q2：QuickAdd 宏不执行？

**A**：
- 检查宏步骤顺序
- 确认文件路径正确
- 逐步测试每个步骤

### Q3：如何共享团队模板？

**A**：
- 将模板文件夹提交到 Git
- 团队成员拉取最新代码
- 统一模板存放位置
