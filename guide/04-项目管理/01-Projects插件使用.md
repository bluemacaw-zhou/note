## 插件简介

**Projects** 是 Obsidian 官方的项目管理插件。

**核心功能**：
- 多种项目视图
- 灵活的数据源
- 强大的筛选和排序
- 丰富的自定义选项

---

## 安装配置

### 安装插件
```yaml
设置 → 核心插件 → Projects → 启用
```

### 创建项目
```
1. 命令面板：Projects: Create a new project
2. 选择项目类型
3. 配置数据源
4. 自定义视图
```

---

## 视图类型

### 1. 表格视图
最常用的视图类型，类似电子表格。

### 2. 看板视图
基于状态分列展示。

### 3. 日历视图
按日期展示任务。

### 4. 画廊视图
卡片式展示，适合图片或简短内容。
