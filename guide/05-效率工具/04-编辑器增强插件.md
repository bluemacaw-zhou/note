## Buttons 按钮

### 插件简介

**Buttons** 允许在笔记中创建交互式按钮，点击后执行各种操作。

**主要功能**：
- 运行命令
- 打开链接
- 插入文本
- 计算 JavaScript
- 打开笔记

### 安装配置

```yaml
# 安装
设置 → 社区插件 → 浏览 → 搜索 "Buttons" → 安装并启用
```

### 基础用法

**语法**：
```markdown
```button
name 按钮名称
type action
icon 图标
```
```

### 实用按钮

**1. 打开今日笔记**
```markdown
```button
name 打开今日笔记
type command
action Periodic Notes: Open today's daily note
```
```

**2. 插入当前时间**
```markdown
```button
name 插入时间
type command
action Editor: Insert current time
```
```

**3. 创建新任务**
```markdown
```button
name 新建任务
type note(Tasks/任务模板)
templater true
```
```

**4. 运行计算**
```markdown
```button
name 计算
type command
action Calculate: Calculate all
```
```

## Sidebar Highlights 侧边栏高亮

### 插件简介

**Sidebar Highlights** 在侧边栏文件列表中添加颜色标记，方便识别重要文件。

**功能**：
- 按颜色标记文件
- 自定义颜色规则
- 快速过滤和搜索

### 安装配置

```yaml
# 安装
设置 → 社区插件 → 浏览 → 搜索 "Sidebar Highlights" → 安装启用
```

### 基础配置

```yaml
# 颜色定义
Colors:
  red: 重要
  yellow: 进行中
  green: 完成
  blue: 参考资料
```

### 使用方法

**方式1：Frontmatter 设置**
```markdown
---
highlight: red
---
```

**方式2：标签触发**
```yaml
# 设置中配置规则
Tag Colors:
  #urgent: red
  #important: yellow
  #done: green
```

**方式3：右键菜单**
- 在文件列表中右键点击文件
- 选择 "Highlight" → 选择颜色

### 脚注高亮演示

**脚注功能**：
Obsidian 支持脚注（Footnotes）功能，可以在文档中添加注释和引用。

**脚注语法**：
```markdown
正文内容[^1]

[^1]: 这是脚注内容
```

**配合 Sidebar Highlights**：
- 有脚注的文件在侧边栏会有特殊标记
- 快速识别哪些文档包含脚注
- 点击脚注计数可快速跳转

**实用案例**：

**学术论文笔记**：
```markdown
---
highlight: yellow
---

# 研究方法

根据相关研究[^1]，我们采用以下方法...

[^1]: 参见文献《Obsidian 知识管理》2024年版
```

**技术文档**：
```markdown
---
highlight: blue
---

# API 接口说明

接口需要认证[^auth]才能访问。

[^auth]: 使用 OAuth 2.0 进行认证
```

**阅读笔记**：
```markdown
---
highlight: green
---

# 书籍阅读笔记

书中提到这个概念[^note1]非常重要。

[^note1]: 第25页的详细解释
```

## 常见问题

### Q1：按钮点击无反应？

**A**：
- 检查命令是否正确
- 确认相关插件已启用
- 查看开发者控制台错误

### Q2：高亮颜色不生效？

**A**：
- 确认插件已启用
- 检查 frontmatter 语法
- 尝试重启 Obsidian

### Q3：如何自定义按钮样式？

**A**：使用 CSS 片段
```css
/* 自定义按钮样式 */
.button-action {
  background-color: #your-color;
  border-radius: 5px;
}
```

> 3. **命名规范**：使用清晰的按钮和规则名称
