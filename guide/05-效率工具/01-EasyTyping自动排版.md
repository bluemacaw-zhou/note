## 插件简介

**EasyTyping** 是一款专为中文用户设计的自动排版插件，解决中英文混排时的间距问题。

**主要功能**：
- 自动在中英文之间添加空格
- 自动在中文与数字之间添加空格
- 智能去除多余空格
- 支持自定义标点符号转换

## 安装与配置

### 安装步骤

1. **打开插件市场**
   - 设置 → 第三方插件 → 浏览
   - 搜索 "EasyTyping"

2. **安装并启用**
   - 点击安装按钮
   - 在已安装插件列表中启用

3. **基本配置**
   - 设置 → EasyTyping
   - 调整个性化选项

### 推荐配置

```yaml
# 基本设置
Auto Capitalize: false        # 禁用自动大写
Auto Pair 两种符号: true       # 自动配对符号
Convert Symbol: true          # 标点符号转换

# 间距设置
Add Space Between Chinese and English: true
Add Space Between Chinese and Number: true
```

## 核心功能

### 1. 自动间距

**中英文之间**：
```markdown
# 输入
这是Obsidian

# 自动变为
这是 Obsidian
```

**中文数字之间**：
```markdown
# 输入
今天是2026年3月6日

# 自动变为
今天是 2026 年 3 月 6 日
```

### 2. 标点转换

**自动转换**：
- `( )` → `（）`
- `" "` → `""`
- `' '` → `''`

**配置示例**：
```yaml
Symbol Conversions:
  - from: '"'
    to: '"'
  - from: "'"
    to: "'"
```

### 3. 智能去空格

**自动去除**：
- 连续空格变为单个空格
- 行首行尾空格
- 全角空格转半角

## 高级配置

### 自定义规则

```yaml
# 排除特定模式
Excluded Patterns:
  - "https?://\\S+"    # URL 不添加空格
  - "\\w+@\\w+\\.\\w+" # 邮箱不添加空格

# 特定符号处理
Special Symbols:
  - "&"
  - "+"
  - "="
```

### 快捷键配置

| 快捷键 | 功能 |
|--------|------|
| `Ctrl/Cmd + ;` | 强制格式化当前行 |
| `Ctrl/Cmd + Shift + ;` | 格式化整个文档 |

## 常见问题

### Q1：某些代码被格式化了怎么办？

**A**：添加到排除列表
```yaml
Excluded Patterns:
  - "```[\\s\\S]*?```"  # 代码块
  - "`[^`]+`"            # 行内代码
```

### Q2：如何禁用自动格式化？

**A**：设置中关闭
- 关闭 "Auto Format on Type"
- 使用快捷键手动格式化

### Q3：与其他插件冲突？

**A**：调整插件顺序
- 在插件设置中调整加载顺序
- 确保 EasyTyping 最后加载
