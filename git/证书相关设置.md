# git证书代理相关设置
公司有代理的情况下 如何设置git代理和证书 方便的同步代码

## 证书形式
mitmproxy-ca-cert.p12 (Windows11)
mitmproxy-ca-cert.cer (Windows7)
mitmproxy-ca-cert.pem (mac证书 也是git能够使用的证书)

## 清除所有SSL相关配置
git config --global --unset http.sslBackend
git config --global --unset http.sslCAInfo
git config --global --unset https.sslCAInfo

## 重新设置基本配置
git config --global http.sslBackend openssl

## 如果你有PEM格式证书
git config --global http.sslCAInfo "D:/Program Files/gitCert/mitmproxy-ca-cert.pem"

## 设置代理
git config --global http.proxy http://127.0.0.1:8080
git config --global https.proxy https://127.0.0.1:8080
