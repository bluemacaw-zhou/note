# 相机基础概念与人机交互语言

这篇笔记整理的是一条主线：

从相机的基本物理原理出发，理解焦距、光圈、景深、对焦这些参数，最后落到拍摄者如何用相机能理解的语言表达自己的拍摄意图。

## 1. 相机看到的是一个视锥体

相机看到的空间可以近似理解成一个从镜头向外展开的矩形视锥体。

因为传感器是矩形，所以相机记录的不是一个圆锥，而是一个矩形截面的视锥体：

```text
横向视角：由传感器宽度决定
纵向视角：由传感器高度决定
对角线视角：由传感器对角线决定
```

常用的视角公式是：

```text
AOV = 2 * arctan(d / (2f))
```

其中：

```text
AOV = 视角
d   = 传感器在某个方向上的尺寸
f   = 焦距
```

如果 `d` 用传感器宽度，算出来的是横向视角；如果用高度，算出来的是纵向视角；如果用对角线，算出来的是对角线视角。

这个公式通常说是近似成立，因为真实镜头不是理想薄透镜。真实拍摄中还会受到镜头结构、畸变校正、对焦距离、视频裁切、电子防抖、标称焦距四舍五入等因素影响。

## 2. 焦距的两层含义

焦距在物理上是光学系统的一个成像参数。对理想薄透镜来说，平行于光轴的光会汇聚到焦平面上的焦点，焦距就是透镜到焦点的距离。

但在摄影里，焦距最直接影响的是视角：

```text
焦距短：视角宽，画面包含更多空间
焦距长：视角窄，画面像被拉近
```

原因是传感器大小固定，而焦距越长，同样角度入射的光在像平面上的位移越大：

```text
像高 ≈ 焦距 * tan(入射角)
```

所以传感器能容纳的入射角范围变小，视角就变窄。

## 3. 为什么远处景物不会都汇聚成一个白点

“平行光经过透镜会汇聚到焦点”这句话容易误解。

更准确的说法是：

```text
同一个方向的一束平行光，会汇聚到焦平面上的一个像点。
不同方向的平行光，会汇聚到焦平面上的不同像点。
```

比如：

```text
画面中心远处物点 -> 汇聚到传感器中心
画面左侧远处物点 -> 汇聚到传感器右侧
画面右侧远处物点 -> 汇聚到传感器左侧
画面上方远处物点 -> 汇聚到传感器下方
```

所以透镜不是把所有光汇聚成一个点，而是把每个物点的光分别汇聚成对应的像点。很多像点排列在传感器平面上，就形成图像。

## 4. 小孔成像与透镜成像的关系

小孔成像的逻辑是：

```text
物体上每个点向四面八方发光
小孔只允许其中很窄的一束光通过
这些光落到屏幕上，形成倒立图像
```

小孔的问题是：

```text
孔很小 -> 图像相对清楚，但很暗
孔变大 -> 图像变亮，但每个物点散成一片，图像变糊
```

透镜解决的是这个矛盾：

```text
允许更多光通过
通过折射，把同一个物点来的多条光线重新汇聚到一个像点
```

所以可以这样理解：

```text
小孔靠“只放过很少光线”来维持成像关系。
透镜靠“折射并重新汇聚光线”来维持成像关系。
```

相机使用透镜，不是为了把所有光集中到一处，而是为了在保留小孔成像几何关系的同时，大幅增加通光量。

## 5. 光圈是什么

透镜本身整片都能透光，但镜头内部通常有一个可调的限光结构，叫光阑。摄影里常说的光圈，通常就是由光圈叶片形成的有效通光开口。

它不是小孔成像里的那个“孔”。两者区别是：

| 项目 | 小孔成像的孔 | 相机镜头的光圈 |
|---|---|---|
| 是否负责成像 | 是 | 不是，主要由透镜成像 |
| 作用 | 只允许极少光线通过 | 控制通过透镜的光线范围 |
| 清晰依赖 | 孔足够小 | 透镜正确对焦 |
| 孔变大后 | 图像迅速变糊 | 图像仍可清楚，但景深变浅 |

光圈叶片的实际意义是让镜头不是永远全开，而是可以控制参与成像的光线数量和光线角度范围。

## 6. 为什么光圈写成 f/8

摄影里的 `f/1.8`、`f/2.8`、`f/8` 不是孔径的毫米数，而是一个比例。

```text
光圈值 N = 焦距 f / 有效孔径 D
```

也就是：

```text
N = f / D
D = f / N
```

摄影习惯写成：

```text
f/N
```

例如 50mm 镜头：

```text
f/2  -> D = 50 / 2  = 25mm
f/4  -> D = 50 / 4  = 12.5mm
f/8  -> D = 50 / 8  = 6.25mm
f/16 -> D = 50 / 16 = 3.125mm
```

所以数字越大，实际孔径越小。

采用 `f/N` 这种比例，是为了让不同焦距镜头的曝光有可比性。例如：

```text
50mm f/2  的有效孔径约 25mm
100mm f/2 的有效孔径约 50mm
```

虽然实际孔径不同，但它们的孔径和焦距的比例相同，所以在同样快门、同样 ISO 下，单位面积获得的照度大致可比。

常见完整档位是：

```text
f/1.4 -> f/2 -> f/2.8 -> f/4 -> f/5.6 -> f/8 -> f/11 -> f/16
```

每往右一档，进光量减半；每往左一档，进光量翻倍。

原因是进光量和孔径面积有关：

```text
面积 ∝ 直径^2
```

要让进光量减半，孔径直径要除以 `sqrt(2)`；对应地，光圈值要乘以 `sqrt(2)`。

## 7. 光圈为什么不能被快门和 ISO 取代

光圈、快门、ISO 都能影响照片亮度，但它们控制的是不同物理问题。

| 变量 | 本质控制 | 主要副作用 |
|---|---|---|
| 光圈 | 进入镜头的光量，以及光线锥的粗细 | 景深、虚化、镜头像差 |
| 快门 | 传感器接收光的时间 | 运动模糊、手抖、视频运动感 |
| ISO | 电子信号放大 | 噪点、动态范围下降 |

快门不能随便改，因为它决定时间效果：

```text
高速快门 -> 冻结运动
慢速快门 -> 保留运动拖影
视频快门 -> 通常需要配合帧率，维持自然运动感
```

ISO 也不能替代光圈，因为 ISO 不增加真实进光量，只是放大已有信号。光少时提高 ISO，会把噪声也一起放大。

光圈是唯一直接改变光学输入的变量，同时还控制景深和镜头像差。因此它不是多余旋钮，而是光学层面的必要自由度。

## 8. 景深、弥散圆与虚化

镜头对某个距离正确对焦时，该距离上的物点光线会刚好汇聚到传感器平面上。

如果某个物点的光线：

```text
还没汇聚就碰到传感器
```

或者：

```text
已经汇聚过，又散开后才碰到传感器
```

它在传感器上就不是一个点，而是一个小圆斑。这个圆斑叫弥散圆。

```text
清楚：
光线 -> . -> 正好落成一个点

失焦：
光线 -> ( ) -> 落成一片圆斑
```

如果弥散圆小到人眼或输出尺寸分辨不出来，我们仍然认为它是清楚的。对焦距离前后，弥散圆仍然小到可接受的范围，就是景深。

所以：

```text
对焦距离上最清楚
前后逐渐变糊
可接受清楚的范围 = 景深
明显糊开的部分 = 虚化
```

大光圈时，通过镜头的光线角度更大。传感器平面稍微偏离汇聚点，弥散圆就会变大，所以景深浅、虚化明显。

小光圈时，光线角度更窄。即使传感器平面没有正好在汇聚点上，弥散圆也比较小，所以景深更深。

入门时可以先记住：

```text
对焦 = 清晰范围放在哪里
光圈 = 清晰范围有多厚
```

但完整地说，景深还受焦距、对焦距离、传感器尺寸、输出尺寸和观看标准影响。

## 9. 对焦的本质

对焦不是纯算法。算法只是判断和控制，最终一定要调整镜头内部的光学元件。

传感器的位置基本固定。对焦时，镜头通常移动内部的某一组镜片，也就是对焦镜组，使目标距离上的物体刚好成像在传感器平面上。

过程可以理解为：

```text
目标距离变化
-> 光线自然汇聚的位置变化
-> 镜头移动对焦镜组，改变光路
-> 让目标距离的光线刚好汇聚到传感器
```

自动对焦系统大致包括：

| 部分 | 作用 |
|---|---|
| 图像传感器/对焦检测 | 判断画面清晰状态 |
| AF 算法 | 识别主体，计算调整方向和幅度 |
| 镜头马达 | 推动对焦镜组 |
| 对焦镜组 | 改变光路 |
| 机身和镜头通信 | 传递控制指令和状态 |

手动对焦和自动对焦的光学本质一样。区别只是：

```text
自动对焦：相机判断并驱动镜片移动
手动对焦：人判断并通过对焦环控制镜片移动
```

现在很多镜头是电子对焦环。转动对焦环时，不一定是机械直连镜片，而是发送电子信号，再由马达移动对焦镜组。但最终仍然是镜片位置发生变化。

## 10. 定焦镜头对焦时会不会破坏焦距

定焦镜头的“定”，不是说内部镜片永远不动，而是说它不能像变焦镜头那样主动、大范围改变视角。

定焦镜头对焦时也会移动镜片组，这可能带来轻微视角变化。这个现象叫呼吸效应，也叫 focus breathing。

严格地说：

```text
定焦镜头对焦时，实际视角可能轻微变化。
```

但它的目的仍然是改变清晰距离，而不是改变焦段。

可以区分为：

```text
变焦 = 主动改变视角
对焦 = 主动改变清晰距离
```

定焦镜头标称的 35mm、50mm，通常指无限远对焦附近的等效焦距。真实镜头在近距离对焦时，实际视角和有效光圈都可能有轻微变化，微距镜头上更明显。

## 11. 人和相机交互的通用语言

拍照时，人不是直接告诉相机“我要拍花、拍人、拍建筑”。相机真正能执行的是：

```text
请把某个距离上的东西成像清楚。
```

所以拍摄者和相机交互的通用语言是空间层。

例如：

```text
相机 -> 1m：花 -> 3m：人 -> 20m：建筑
```

如果你说“拍花”，翻译成相机语言就是：

```text
对焦距离 = 花所在距离
景深 = 按需要覆盖花的关键部分
```

如果你说“拍人”，翻译成：

```text
对焦距离 = 人脸或眼睛所在距离
景深 = 至少覆盖你认为重要的面部范围
```

如果你说“花、人、建筑都要清楚”，翻译成：

```text
对焦距离 = 选择一个合适的中间距离
景深 = 做厚
```

所以可以把拍摄意图拆成两个问题：

```text
1. 我希望哪一层最清楚？
2. 我希望清晰范围有多厚？
```

具体功能只是输入方式：

| 操作方式 | 本质 |
|---|---|
| 触摸对焦 | 告诉相机这个画面位置对应的空间层 |
| 单点对焦 | 告诉相机测这个小区域的距离 |
| 人眼识别 | 让相机自动寻找人眼所在的空间层 |
| 半按快门锁焦 | 固定当前测得的对焦距离 |
| 手动对焦 | 人直接调整清晰层的位置 |

一句话总结：

```text
拍摄者的意图语言是“空间层”。
相机的执行语言是“对焦距离”。
相机功能只是把人的空间层选择翻译成对焦距离。
```

## 12. 如何告诉相机对焦到 10 米

多数相机不是让你直接输入“10m”，而是让你对准 10m 处的参照物完成对焦。

常见方式有三种：

### 12.1 对准 10 米处的物体自动对焦

```text
相机 -> 10m -> 参照物
```

把对焦点放到参照物上，半按快门或按 AF-ON，相机就会把对焦距离调到该物体所在距离。

### 12.2 手动对焦到 10 米

如果镜头或机身能显示对焦距离，可以切换到 MF，转动对焦环直到接近 10m。

但很多现代无反镜头是电子对焦，没有机械距离窗，精确性不一定好。

### 12.3 预对焦

预对焦是实战中很常用的方法：

```text
1. 找一个和目标距离相同的参照物
2. 对它对焦
3. 锁住对焦距离
4. 等真正主体进入这个距离层
5. 按下快门
```

比如想拍 10m 远的人的面部细节，可以先对 10m 左右的电线杆对焦。如果电线杆和人位于差不多同一个距离平面，就可以锁住对焦距离，再拍人。

注意这里锁住的是对焦距离，不是焦距。

## 13. 预对焦的限制

预对焦成立的关键条件是：

```text
参照物和真正主体必须位于差不多同一个距离平面。
```

如果参照物是 10m，人实际是 8m 或 12m，大光圈下人脸可能就不够清楚。

预对焦适合：

```text
主体还没进入画面
相机对目标识别不稳定
光线太暗，自动对焦困难
中间有玻璃、栏杆、树枝干扰
街拍、运动、舞台等固定位置抓拍
```

不适合：

```text
主体一直向你走来
目标距离快速变化
需要持续追踪人眼或动物眼睛
```

这种情况通常应该使用连续自动对焦。

## 14. 为什么不是完全 AI 自动拍照

现代相机已经有很多 AI 辅助：

```text
人眼识别
动物识别
车辆识别
主体追踪
自动曝光
自动白平衡
场景识别
手机多帧合成、HDR、夜景、人像虚化
```

但它仍然不能完全替代拍摄者，因为拍照不只是技术正确，还包含创作意图。

比如同一个场景：

```text
前景有花
中景有人
远景有建筑
```

相机不知道你真正想表达的是：

```text
花清楚，人和建筑虚掉
人清楚，花和建筑作为环境
建筑清楚，人只是前景剪影
三者都尽量清楚
```

这些没有唯一正确答案。

AI 能帮助解决的是：

```text
哪里可能是人眼
当前是否合焦
主体是否移动
曝光是否过亮或过暗
颜色是否大致正常
```

但它很难替你决定：

```text
主体是谁
背景要不要保留
虚化要多强
什么时候按快门
照片想表达什么
```

所以更现实的关系是：

```text
人决定意图
相机和 AI 负责把意图执行得更稳定
```

## 15. 实践经验摘要

拍人：

```text
优先对眼睛，尤其是近距离和大光圈。
多人拍摄时，尽量让人站在同一距离平面。
```

拍花、静物、美食：

```text
对焦到最想让观众看的细节。
如果主体有厚度，大光圈可能只清楚一小片，需要适当收光圈。
```

拍风景：

```text
不要无脑对无限远。
通常需要小光圈，并选择一个能兼顾前景和远景的对焦距离。
```

拍运动：

```text
优先使用连续自动对焦。
如果运动路径固定，可以预对焦到主体将经过的位置。
```

复杂场景：

```text
当相机容易追错主体时，缩小对焦区域或使用触摸对焦。
隔着玻璃、栏杆、树枝拍摄时，自动对焦可能会对到障碍物，需要明确指定对焦层。
```

大光圈近距离拍摄：

```text
不要大幅度先对焦再重新构图。
重新构图可能让焦平面偏移，导致眼睛失焦。
```

## 16. 核心总结

可以把前面的概念压缩成几句话：

```text
焦距决定视锥体的宽窄，也就是视角。
光圈决定有效通光开口，也影响景深、虚化和画质。
对焦决定最清楚的空间层在哪里。
景深决定这层前后有多厚还能被认为清楚。
虚化来自目标距离之外的光线没有在传感器上汇成点，而是形成弥散圆。
```

人和相机交互的核心语言不是“物体名称”，而是：

```text
我要哪一层清楚？
我要清楚范围多厚？
我希望其他层保留还是虚掉？
```

相机的各种功能，都是围绕这几句话展开的输入方式和执行机制。
