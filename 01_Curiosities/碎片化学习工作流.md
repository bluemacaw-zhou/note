# 碎片化学习工作流 (0 成本方案)

记录针对长文档听书、即时语音笔记的 0 成本、无 AI API 费用、本地化执行的工作流方案。

## 1. 核心痛点场景
1. **长文档朗读** (上下班通勤听书)。
2. **多模态即时记录** (灵感爆发实时捕获)。

## 2. 技术方案
- **听书**：Edge-TTS (免费真人音质)。
- **语音记事**：本地 Whisper (私有化/零费用转录)。
- **闭环管理**：通过 VPN 隧道将 Mac Mini 与手机打通，数据收纳至 Obsidian 库。
