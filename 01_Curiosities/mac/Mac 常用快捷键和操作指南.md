# **Mac 常用快捷键指南**

## **一、窗口管理 - Rectangle**

**安装**：`brew install --cask rectangle`

**常用快捷键**：

- `Ctrl + Option + Enter` - 最大化窗口（保留 Dock 和菜单栏）
- `Ctrl + Option + ←` - 左半屏
- `Ctrl + Option + →` - 右半屏
- `Ctrl + Option + ↑` - 上半屏
- `Ctrl + Option + ↓` - 下半屏
- `Ctrl + Option + C` - 窗口居中

**拖动操作**：

- 拖到屏幕上边缘 = 最大化
- 拖到左/右边缘 = 左/右半屏

---

## **二、原生窗口最大化**

**Option + 点击绿色按钮**：

- 按住 `Option` 键 + 点击窗口左上角绿色按钮
- 效果：Windows 式最大化（保留 Dock）

**区别**：

- 直接点绿色按钮 = 全屏模式（隐藏 Dock）
- Option + 点绿色按钮 = 最大化（显示 Dock）

---

## **三、截图快捷键**

**基础截图**：

- `Cmd + Shift + 3` - 截取整个屏幕 → 保存到桌面
- `Cmd + Shift + 4` - 截取选定区域 → 保存到桌面
- `Cmd + Shift + 5` - 打开截图工具栏（推荐）

**截图到剪贴板**（不保存文件）：

- `Cmd + Ctrl + Shift + 3` - 全屏到剪贴板
- `Cmd + Ctrl + Shift + 4` - 选区到剪贴板

**选区截图技巧**（`Cmd + Shift + 4` 之后）：

- 拖动 = 选择区域
- 按 `Space` = 切换到窗口截图模式
- 按 `Esc` = 取消

**截图工具栏**（`Cmd + Shift + 5`）：

- 可以录屏
- 设置保存位置
- 定时截图

---

## **四、其他常用快捷键**

**通用**：

- `Cmd + C/V/X` - 复制/粘贴/剪切
- `Cmd + Z` - 撤销
- `Cmd + W` - 关闭窗口
- `Cmd + Q` - 退出应用
- `Cmd + Tab` - 切换应用
- `Cmd + Space` - Spotlight 搜索

**iTerm2**：

- `Cmd + T` - 新建标签页
- `Cmd + D` - 垂直分屏
- `Cmd + Shift + D` - 水平分屏
- `Cmd + K` - 清屏
