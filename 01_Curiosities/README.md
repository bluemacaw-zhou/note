# 01_Curiosities · 好奇心兴趣池

> 这里是我作为"人"的底色。无压力、非功利。
> 凡是触动好奇心的种子，不论能否变现、不论是否"有用"，都先在这里落地生根。

---

## 当前活跃兴趣点

### 🤖 AI · 人工智能
从 GPT 的底层原理到 RAG 的工程实践，从向量数据库的选型到 Agent 的架构设计。
AI 正在重塑每一个领域的边界，我想亲手感受这个边界在哪里。

### 🎧 学习流 · 碎片化闭环
上下班听书，走路时录音。
从 Edge-TTS 到本地 Whisper，从语音到文字——把所有零碎时间，都变成大脑的养分。
- [[碎片化学习工作流|碎片化学习工作流 (0 成本方案)]]

### ⌨️ Emacs · 编辑器哲学
不只是一个编辑器，是一种对"工具可塑性"的极端信仰。
Doom Emacs 是起点，Lisp 的世界是终点——或者说根本没有终点。

### 📐 UML · 可视化思维
语言会撒谎，图不会。泳道图、时序图、类图——
把混沌的系统思维变成可以对话的语言。

### ☸️ K8s · 容器编排
从 Docker 到 K8s，是从"跑起来"到"管好它"的跨越。
分布式系统的复杂性在这里被暴力压缩成几个 YAML 文件，迷人又危险。

### 🍎 Mac · 工具美美学
好的工具应该消失在意识里。
快捷键、手势、工作流——把摩擦力磨到零。

### ✏️ Apple Pencil · 手脑直连
当手指触碰屏幕，思维和媒介之间的距离消失了。
手绘笔记、Excalidraw、iPad 工作流——探索手写与数字的边界。

### 📦 Obsidian · 知识操作系统
不只是笔记软件，是我的第二大脑的基础设施。
双链、Canvas、插件生态——我想把它推到极限看它能做什么。

### 🖨️ 3D 打印 · 数字到物理的魔法
把脑子里的形状打印出来。
从 CAD 建模到切片参数，从 PLA 到树脂——这是现代的炼金术。

### 🎨 文艺复兴大师 · 跨域实验精神
达芬奇不是画家，米开朗基罗不是雕塑家，他们是实验者。
在艺术、科学、工程之间反复横跳的方式，才是我真正想学习的东西。

## 流转规则

- 兴趣在这里**萌芽**，不强求产出
- 当某个兴趣与 `02_Spheres` 的某个职责碰撞时，移入 `03_Collisions` 开启实验
- 实验结束后，**精华回流到这里**，更新对应兴趣点的认知；过程存入 `04_Chronicles`
