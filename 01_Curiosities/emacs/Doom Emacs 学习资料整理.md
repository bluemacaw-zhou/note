  - 基本快捷键配置

### 核心概念
- **模块系统 (Modules)**:
  - `:completion` - 自动补全
  - `:ui` - 界面相关
  - `:editor` - 编辑器功能  
  - `:emacs` - Emacs 核心功能增强
  - `:term` - 终端相关
  - `:checkers` - 语法检查
  - `:tools` - 开发工具
  - `:lang` - 编程语言支持
  - `:email`, `:app` - 应用程序

### 配置文件结构
```
~/.doom.d/
├── init.el      # 模块启用配置
├── config.el    # 个人配置
└── packages.el  # 额外包管理
```
