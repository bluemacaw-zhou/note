# 利率之锚：逆回购利率 vs 国债利率

## 一、两个"锚"的本质区别

### 逆回购利率 - 政策利率之锚
- **性质**：央行主动设定的政策工具
- **期限**：超短期（主要是7天）
- **作用**：表明央行的政策立场和意图
- **锚定对象**：短期市场利率（银行间拆借利率等）

### 国债利率 - 资产定价之锚
- **性质**：市场交易形成的利率
- **期限**：中长期（主要看10年期）
- **作用**：其他资产定价的基准参考
- **锚定对象**：企业债、股票、房贷等各类资产

---

## 二、传导关系

```
央行设定逆回购利率（如1.80%）
    ↓
影响短期市场利率（银行间7天回购利率围绕1.80%波动）
    ↓
影响国债收益率（资金成本变化影响债券需求）
    ↓
影响其他资产定价（企业债、股票、房贷等以国债为基准加风险溢价）
```

**关键点**：
- 逆回购利率是**源头**，央行的政策信号
- 国债利率是**桥梁**，连接政策与市场
- 最终影响实体经济融资成本

---

## 三、实际应用举例

### 例1：央行降低逆回购利率

**操作**：央行将7天逆回购利率从1.90%降至1.80%

**传导过程**：
1. 银行间7天回购利率跟随下降
2. 银行资金成本降低，更愿意买债
3. 10年期国债收益率从2.5%降至2.4%
4. 企业债利率下降，企业融资成本降低

### 例2：企业债券定价

**10年期国债收益率**：2.5%

**企业债定价**（以国债为基准）：
- AAA级企业债 = 2.5% + 0.5% = 3.0%
- AA级企业债 = 2.5% + 1.0% = 3.5%
- A级企业债 = 2.5% + 2.0% = 4.5%

信用等级越低，风险溢价越高。

---

## 四、对比总结

| 维度 | 逆回购利率 | 国债利率 |
|------|-----------|---------|
| **设定方式** | 央行主动设定 | 市场交易形成 |
| **期限** | 7天（超短期） | 10年（中长期） |
| **调整频率** | 较频繁 | 相对平稳 |
| **代表意义** | 政策立场 | 市场预期 |
| **影响范围** | 短期流动性 | 资产定价体系 |
| **典型应用** | 货币基金、银行理财收益 | 企业债定价、股票估值 |

---

## 五、记忆要点

**逆回购利率（政策利率）**
- 央行的"方向盘"
- 短期利率看它
- 反映政策意图

**国债利率（市场利率）**
- 市场的"温度计"
- 资产定价看它
- 反映市场预期

**关系**
- 逆回购利率影响国债利率
- 国债利率反映政策效果
- 两者共同构成利率体系

---

## 六、投资者关注重点

**关注逆回购利率变化→判断政策方向**
- 利率下调 = 宽松信号
- 利率上调 = 收紧信号

**关注国债利率变化→判断资产性价比**
- 国债收益率上升 = 债券承压，股票相对吸引力上升
- 国债收益率下降 = 债券受益，股票估值压力增加

**核心逻辑**
- 先看政策（逆回购）
- 再看市场（国债）
- 最后决策投资
